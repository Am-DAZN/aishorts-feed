Small 4B AI agent learns to use computers with clicks and code

Researchers released Mage-VL-Cowork, a small AI model with 4 billion parameters that can operate a computer. It mixes two skills in one system: working with on-screen buttons and menus, and running code in a terminal. The team trained it in five stages, using practice, guided examples and reinforcement learning, which rewards good results. To get enough training data, they built a tool called Mage-CUA-Forge. It generated 293,806 desktop and web tasks across 6,915 skills and cut the recurring cost per task by 82.6%. Instead of simply copying a standard teacher model, they improved the teacher's setup first to get better example runs. The model scores 66.0% on OSWorld-Verified, a test of computer tasks. The authors say this is the best result for a model of its size, which matters for AI running directly on personal devices.
