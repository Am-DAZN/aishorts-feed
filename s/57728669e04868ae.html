Gemini API adds Tool Retrieval to help agents use many tools

Google has launched a new feature called Tool Retrieval in the Gemini API. It is now in preview, which means it is still an early version open for testing. The feature lets AI agents, which are programs that carry out tasks on their own, get access to hundreds of tools. Tools are things an agent can use, such as a calendar or a search function. Google says the feature uses fewer tokens. Tokens are the small chunks of text an AI model reads and pays for, so using fewer can mean lower cost and less clutter. For developers building agents, this could make it easier to connect many tools at once.
