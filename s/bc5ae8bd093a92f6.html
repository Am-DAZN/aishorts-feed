PRKV Trims LLM Memory Use by Ranking Which Tokens Matter

Large language models keep a memory of earlier text, called the KV cache, and it grows very large for long inputs. Researchers introduce PRKV, a method that decides which parts of this memory to throw away. It uses Personalized PageRank, a ranking idea from web search, on the model's attention patterns. This lets it spot tokens that matter indirectly, not just recent ones. It needs no extra training and does not change the model. Tests covered long-document understanding, sparse retrieval and step-by-step reasoning on several model families. Even when cutting memory by up to 90%, PRKV stayed competitive with existing methods, lowered peak memory use, and added little extra run time. The results suggest a good balance between accuracy and memory for long inputs.
