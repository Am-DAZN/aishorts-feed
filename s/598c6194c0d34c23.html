Qodo adds company coding rules to Codex for code review

Qodo has built a tool that works with OpenAI's Codex, an AI system that helps write and check code. The tool feeds Codex a company's own knowledge and coding standards. With that context, developers can find P0 issues, meaning the most serious problems, across several code repositories. They can do this before they open a pull request, which is a request for teammates to review and merge new code. The aim is to catch major bugs earlier, so human reviewers spend less time on them. The source gives few other details.
