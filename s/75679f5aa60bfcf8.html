OpenAI's Daybreak Red launches in AWS GovCloud (US-East)

OpenAI says Daybreak Red is now available in AWS GovCloud (US-East), a cloud region built for U.S. government use. It brings GPT-5.6 Cyber, an AI model made for cybersecurity, to approved customers. They can reach it through Amazon Bedrock, Amazon's service for using AI models. The model is meant only for authorized cybersecurity work. The announcement says little beyond that, so details on features and pricing are not yet clear. It matters because it puts a specialized AI tool within reach of government-focused security teams.
