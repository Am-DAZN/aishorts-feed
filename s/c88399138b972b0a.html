Middle Layers of AI Language Models Need More Capacity Than Edge Layers

Most large language models give every layer the same size of feed-forward network, a block that processes information inside each layer. Researchers asked if that is wise. They used a statistical method called PCA to measure how many dimensions each layer really uses. They checked 58 open models from 14 families, ranging from 70 million to 72 billion parameters. Middle layers used more dimensions than the first and last layers. This pattern held across English and Chinese data and mostly survived fine-tuning. To test it, the team shrank models using this pattern while keeping the same size budget. It beat equal-width shrinking by 2.3 points on Qwen3-8B and 2.5 on Qwen2.5-3B. Gains were smaller on Gemma-3-4B (0.9) and LLaMA-3-8B (0.5). The code is public.
