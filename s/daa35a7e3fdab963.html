New Method Lets AI Rebuild and Vary Data Analyses From Plain-Language Steps

Sharing code does not show why an analysis was done a certain way. Code buries key choices in technical detail, and papers scatter them or skip the small ones. Researchers propose a schema, a structured plain-language list of every decision in an analysis, from cleaning data to choosing a model. Large language models (LLMs) can then write and check the analysis scripts from that list. The same list can grow into a multiverse, a set of alternative versions of the analysis ready to compare. In one test, the team reproduced the reported results of a published study on smoking data and automatically coded a change a reviewer suggested. In another, they used the workflow to check reproducibility in a football study with many analysts. The schema sits between the paper and the code, helping readers understand and extend an analysis.
