Sable Proves an AI Model Produced a Given Output, Bit for Bit

Sable is a new system that lets someone prove that a specific language model generated a specific response to a prompt. The model must be converted to whole-number math, so every step gives the same result each time. The proof runs on one GPU. On Qwen2.5-32B, it takes 92.5 seconds for 4,096 tokens, about 41 to 50 times the normal serving time. That is roughly 6.4 cents per request at public GPU prices. The authors say it is 40 to 64 times faster per parameter and token than an earlier system, zkLLM. A checker can verify a proof on one CPU core in 19 to 56 seconds. The whole-number version of the model stays close to the original in tests. The proof does not hide the model's details, so it targets open-weight models.
