Simon Willison hides AI-written pull request text behind a fold

Developer Simon Willison now gets most code changes from AI coding agents like Claude Code and Codex. These agents write long, accurate descriptions of each pull request (a proposed code change). He says the length makes them read like slop, and he does not want to read all of it. His fix is simple. He writes a short human-chosen opening that says what the change is for, sometimes with a screenshot. The full agent text goes inside an HTML details/summary block, which GitHub shows as a collapsed section. He labels it with the model name, such as Claude Opus 5.5 Medium. Readers get the key point fast, and the detail is still there.
