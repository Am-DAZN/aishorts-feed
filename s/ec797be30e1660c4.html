Muir, a new linear attention design, beats rivals on quality and handles 10M-token streams

Linear attention is a way for language models to read long text using a small, fixed memory instead of one that keeps growing. Researchers introduce Muir, which builds on an earlier model called Gated DeltaNet-2. They found that memory updates care more about what is written than what is erased, so the erase controls can be smaller. They also found some memory rows grow too large and drown out others, so Muir re-weights them when reading. Saved parameters go to a wider feed-forward network. From 166M to 1.34B parameters, Muir lowers perplexity (a measure of prediction error) by 1.8-2.0% over the earlier model and 2.5-3.6% over Transformers. At 1.34B, it handles text streams of 10M tokens without quality drift, and it trains 2.7x faster than a Transformer at 32K length.
