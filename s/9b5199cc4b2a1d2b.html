New Method Trims Features in Datasets With Missing Values, But Not Accuracy

Researchers propose COFRS, a way to pick the most useful columns in a dataset when some values are missing. Older methods often treat a missing value as a match for anything. COFRS does the opposite. It compares two records only on the columns both have, then divides by the total number of columns, so gaps count against similarity. On 11 public datasets, it kept the fewest columns on average: 4.1, versus 5.0 to 11.2 for other methods. The gap was statistically significant against three rivals, but not against Tolerance-RS. With one classifier type, accuracy was similar across methods. With another, COFRS ranked last. The authors conclude the gain is a smaller feature set, not better predictions.
