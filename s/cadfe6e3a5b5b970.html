ReLift repairs 3D point tracks lifted from 2D trackers in video

Tracking every point of a scene in 3D from a single video is hard, especially when objects block the view. Most methods try to learn tracking, depth and hidden motion all at once, but there is little 3D training data. ReLift takes a different route. It starts with strong existing 2D trackers and 3D geometry models, then lifts the 2D tracks into 3D. Those lifted tracks contain errors, and when a point is hidden, the depth often comes from the object in front. ReLift is a model that fixes these tracks, keeps reliable points and fills in missing motion. It trains on 3D trajectories with simulated errors, not images, so it works with different trackers and geometry models without retraining. On the WorldTrack test, it beat the strongest baselines by 2.1 APD on all points and 3.0 on moving points. Faster versions stay competitive and run faster than 4RC.
