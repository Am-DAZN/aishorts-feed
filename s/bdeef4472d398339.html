AI Agent Runs Lab Instrument Within Human-Set Limits, Matches Chemists

Researchers built an AI agent for self-driving labs, where robots run experiments with little human help. The agent sits between analyzing results and designing the next experiment. It can only take actions on lab hardware that are authorized, checked and logged, and it knows when to ask a human. The team tested it on a liquid chromatography-mass spectrometry machine, which identifies chemicals in a sample. The task was to screen oxidants, chemicals used to make an organic dye. The agent submitted jobs, read the data, flagged failed experiments and ranked the oxidants. Its ranking matched a standard scripted method, and chemists confirmed its readings. In a replay simulation, it found the best condition by about its seventh injection, versus 14.5 for random order. This suggests labs can gain autonomy while keeping AI actions limited and checkable.
