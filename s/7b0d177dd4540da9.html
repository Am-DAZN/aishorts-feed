CAFIN Speeds Up AdaFisher Training Optimizer by Fusing GPU Steps

Some training methods use extra information about how a model's error changes, called second-order optimizers. They can help models learn, but they run slowly on graphics chips (GPUs). Researchers built CAFIN to speed up one of them, called AdaFisher. It merges many small GPU steps into a few combined ones, so the chip moves less data and creates fewer temporary files. The math of AdaFisher stays the same. In tests with ResNet-18 on three image datasets and two consumer GPUs, a key calculation ran up to 78.4% faster. Each full optimizer step was 2.1% to 26.9% faster. It also avoided about 18.91 MB of temporary memory per step. Accuracy stayed comparable to the original. This shows that smarter GPU code can make advanced training methods more practical.
