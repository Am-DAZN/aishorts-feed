HiUni Uses One Shared Model to See and Draw Images

Researchers have built HiUni, an AI model that both understands images and creates them. Many similar systems keep separate parts for these two jobs. HiUni instead reuses the same image reader and the same core network for both, and only the final output stage differs by task. This is hard because making images pixel by pixel is tricky to train, and the image reader drops fine details needed for drawing. The team added a Pixel Diffusion Head, which helps the model generate pixels directly, and a small pathway called HiGate, which passes fine detail near the end. In tests, HiUni scored about the same as the original model on understanding, and did competitively on image generation and editing. The authors say this points to a simpler way to build models that handle both tasks.
