Wizard lets players control characters in AI-generated game worlds in real time

Researchers have built Wizard, an AI system that generates game worlds as video and lets players steer characters as it plays. Earlier systems worked only in simple games, used preset moves, and struggled with new scenes or characters. Wizard is meant to handle new scenes, characters and actions without extra training. The team built a dataset of 750 scenes and 178 characters, including skeleton and shape data. This data guides the video model, so the picture follows the character's movements. A masking step helps the video match those guides. An agent also tracks the game state, such as what is happening in the world, and updates it as play goes on. This lets players set up their own worlds while keeping the visuals and game rules consistent. The work points toward games that players can create themselves.
