llm-anthropic 0.31 adds Anthropic's new Fable 5.2 and Mythos 5.2 models

Simon Willison has released version 0.31 of llm-anthropic, a plugin for his LLM command-line tool. It adds support for two new Anthropic models, Fable 5.2 and Mythos 5.2, released the same day. Users can install the tool and run prompts with a single command. Willison tested Fable 5.2 by asking it to draw an SVG of a pelican riding a bicycle at five reasoning levels, from low to max. The best result came from xhigh. The max level returned no image at all. It ran out of tokens after using 128,000 on thinking. Willison saw the same bug with Opus 5.5. It is new for the Fable series, since Fable 5 and 5.1 handled max effort fine.
