Why the system around an AI model matters more than the model

An MIT Technology Review piece argues that the edge in enterprise AI now comes less from picking a model and more from the "serving harness," the engineering system around it. This covers architecture, memory use, and scheduling. The article says teams should start with the workload, since a fast customer chat tool needs differ from an overnight document job. A slightly better model may not be worth it if it doubles costs or misses speed targets. It also warns that these choices affect one another. For example, GPU memory can run short as more users connect, even when computing power is free. Its advice: measure first, find the main bottleneck, fix it, then measure again.
