StateBench Tests How AI Models Track Changes Across Long Documents

Hugging Face has published a blog post about StateBench. From the title, it is a test for language models. It checks how well they keep track of state changes in long documents. A state change is when something shifts as a text goes on, such as an object moving or a fact being updated. This matters because AI models often read long texts and must remember what is true at each point. The source gave no further details, so results and methods are not covered here.
