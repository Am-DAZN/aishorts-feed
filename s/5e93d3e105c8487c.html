LightningMoBA speeds up long-text AI generation by up to 1.6x

Long inputs make AI models slow, because each word must look back at everything before it. Mixture of Block Attention (MoBA) cuts this cost by having each query check only some chunks, or blocks, of earlier text. A prior tool, FlashMoBA, runs MoBA well but always picks a fixed number of blocks and organizes work around each query. Researchers now present LightningMoBA. It sets block choices by score thresholds, so the count can vary. It also groups work by the block of data being read, so the GPU can reuse loaded data. On Hopper GPUs, it overlaps data transfers with computation. Across five models at matched settings, generation ran 1.20 to 1.60 times faster. The average RULER long-context score rose from 74.42 to 75.28.
