Python Software Foundation opens its end-of-year fundraiser

The Python Software Foundation (PSF), the non-profit behind the Python programming language, has launched its end-of-year fundraiser. Simon Willison, who sits on the PSF board, is asking companies and people who benefit from Python to donate. The PSF looks after Python's intellectual property, runs PyPI (the main site for sharing Python software), sponsors sprints for core developers, and supports community events like PyCon US. It also pays a small staff team. Its Developers in Residence program now includes three security developers, including new member Brett Smith. They work on keeping Python, PyPI and the wider ecosystem safe.
