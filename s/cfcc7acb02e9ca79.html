OpenAI adds agents and plugins to ChatGPT for Healthcare

OpenAI has announced new features for ChatGPT for Healthcare, its version of ChatGPT built for the health sector. The update includes computer-use agents, which are AI tools that can operate software on a screen much like a person would. It also brings improved clinical answers, meant to make responses to medical questions better. Finally, new healthcare plugins will work across different healthcare software. OpenAI says the goal is to help the tools get real work done, not just answer questions. The announcement gives few details, so how well the features perform is not yet clear.
