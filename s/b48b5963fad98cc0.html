Open-Source CADMAGEDDON Rebuilds Editable CAD Models From Meshes on a Laptop

Researchers have released CADMAGEDDON, an open-source AI agent that turns 3D meshes into editable CAD files. It can run locally on a single GPU or a current laptop. That matters because many CAD users work with private parts they do not want to send to outside services, and small teams often cannot afford large computing setups. The agent breaks the job into a series of simple visual choices about what to build and what to fix. Geometric tools handle the precise construction, so the AI can focus on looking and reasoning. Using the mid-sized Qwen3.8-27B model, it beats earlier methods, including ones built on frontier models, on all the main benchmarks for reconstruction quality. It also connects to FreeCAD, so results fit into existing CAD workflows. The code is available on GitHub.
