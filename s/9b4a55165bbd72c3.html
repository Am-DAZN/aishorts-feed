Simon Willison builds a page to compare HTML select box styles

Developer Simon Willison was annoyed that HTML select boxes (dropdown menus) look different in each browser. He also finds them ugly in Chrome. So he had an AI model, which he calls Claude Fable 5.2, build a page showing many ways to style them. He plans to take screenshots in desktop and mobile browsers. After testing, he picked a favorite set of CSS, the code that controls how web pages look. It removes the default look, adds a thin gray border, rounded corners, padding and a small custom arrow icon. He shows how it looks in three browsers. It is a handy starting point for anyone who wants dropdowns to look the same everywhere.
