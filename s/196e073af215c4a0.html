Datasette Agent adds side panel chat for building database apps

Simon Willison has released datasette-agent 0.5a0, a significant update to Datasette Agent. The main new feature is called the panel. It lets the agent chat open and stay beside Datasette pages, such as a table or a query page. When used with datasette-apps, you can ask for a database-backed app in the chat and it gets created. You can then keep changing the app from the same chat that sits next to it. This makes it easier to build and adjust apps without leaving the page. You can try it by signing in with a GitHub account at agent.datasette.io.
