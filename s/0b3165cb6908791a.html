MGMem Gives AI Agents Long-Term Memory Without Costly Rewriting

AI agents that chat over thousands of turns need to remember past conversations. Many systems ask a language model to rewrite old chats into summaries or facts. That is costly, can give different answers each run, and hides the original words. MGMem takes another route. It makes no generative calls to build its memory. Instead, it uses fixed, rule-like parsers to link people and topics that recur across sessions into a graph. When a question comes in, it finds the right subject and returns the original conversation snippets. On the LoCoMo test, it beat comparable baselines. On LongMemEval-S, it stayed competitive and led or tied on single-session questions among local retrieval methods. The code is public.
