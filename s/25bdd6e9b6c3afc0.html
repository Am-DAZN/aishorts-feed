FactEmbed helps AI better find images from a photo plus an edit note

Composed image retrieval means finding a target image from a reference picture and a short text describing a change, such as "same dress, but in red." Researchers say current methods built on multimodal large language models (AI that handles text and images) do not use the model's understanding well. They squeeze the query straight into one search code without first working out what change is wanted. The new method, FactEmbed, adds a set of internal "factor" signals that first imagine what the target image should look like. Only then does it build the code used for search. It also reuses the same forward pass to quickly rerank a short list of candidates, at very low extra cost. The authors report that FactEmbed beats earlier approaches on several standard image retrieval tests.
