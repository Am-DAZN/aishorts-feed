EvoGroup Lets Team AI Agents Improve Their Own Memory Setup

Some AI agents now work as digital team members, using chats and files shared by many people. Most agent memory tools are built for one user, so they miss group ties and knowledge built together. Researchers propose EvoGroup, a system that starts with just six tools and rewrites its own setup, called a harness, as it works. It picks useful past runs using the agent's confidence and results, and asks the agent to reflect when it was unsure. Other agents then study these runs and revise the harness. On a test set from EverMemBench, the pass@1 score rose from 71.07% to 89.58%. That beat human-designed setups, including Claude Code at 85.83%. When frozen and tried on a new test, GroupMemBench, with GPT-5.5, it also did well against other methods.
