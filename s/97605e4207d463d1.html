CaPtain trains a small open AI model to control robots by writing code

Researchers built CaPtain, an open training pipeline that teaches a small vision-language model to control robots by writing code. Until now, such robot agents relied on closed frontier models or pre-trained robot-action models. Small open models failed completely. CaPtain first fine-tunes the model on example runs made with GPT-6 Astra. It then uses reinforcement learning, which improves the model by trial and error. A new "physical critic" uses hidden simulator data to judge which steps helped. Starting from Qwen3.5-4B, which scored 0% at first, the model reached 73.8% success on LIBERO tests. It scored 78.5% on LIBERO-PRO, beating several frontier-model agents. It also worked on a real robot after training only in simulation. The team released all code, data, and model weights.
