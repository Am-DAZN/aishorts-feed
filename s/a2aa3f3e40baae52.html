Small Local Model Handles Half of Database Questions, Cutting AI Agent Costs by a Third

Large AI agents are very accurate at turning plain-language questions into database queries (called text-to-SQL). But they are slow, costly, and send private queries to outside servers. Researchers built LuthorSQL, a 7-billion-parameter model that runs on a single local GPU. It works in one pass and answers in 0.84 seconds. Alone, it scored 68.03% on a hidden BIRD test set. Paired with Claude Opus 5.5, it answers nearly half of questions locally and passes only uncertain ones to the big model. In tests on 227 questions, this cut API cost by 33.3% with the same accuracy. It also worked on several other database systems with small accuracy drops. The team also found that Opus can reproduce many public benchmark answers from memory, but it still did well on newer databases. Code and data are public.
