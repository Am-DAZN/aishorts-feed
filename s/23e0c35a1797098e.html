NVIDIA Unveils Four-Node DGX Spark Kit for Desktop Supercomputing

At the SC26 supercomputing conference in Chicago, NVIDIA introduced the DGX Spark HPC Developer Kit for researchers, academics and developers. It links four small DGX Spark systems directly to each other, with no network switch needed. Together they offer 512GB of memory and 20TB of storage. NVIDIA says this can run models of up to 700 billion parameters locally. The idea is that researchers can test and debug science and AI work at their desk instead of waiting in a queue for a shared computer cluster. It also keeps unpublished results and private data on site. A setup guide for NVIDIA's HPC software tools is coming soon. Early users include a UC Berkeley lab, which says results arrived 15x sooner than on a cluster.
