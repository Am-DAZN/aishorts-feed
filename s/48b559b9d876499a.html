TorchCurves Lets AI Models Learn Smooth Curves as Building Blocks

TorchCurves is a new library for PyTorch, a popular tool for building AI models. It treats curves, which are smooth lines defined by a few numbers, as parts a model can learn. You feed in numbers, and it returns points on a curve. The curves can be built from B-splines or Legendre polynomials, two standard math methods. The curve settings can be trained along with the rest of the model, or produced by another network. The library supports uses such as turning continuous features into model inputs, Kolmogorov-Arnold networks, and functional regression. It is written in plain PyTorch with no custom hardware code, which keeps it easy to read and maintain. Timing tests compare it with NumPy, SciPy and EfficientKAN. The authors say the results show where it runs well and where it adds a lot of overhead. The code is on GitHub.
