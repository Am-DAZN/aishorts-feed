Sage Flash, a 320B-parameter AI model, targets science reasoning and computer tasks

A new technical report describes Sage Flash, a 320-billion-parameter AI model built to reason over scientific evidence and act in interactive settings. It uses special encoders for molecules, biological sequences and spectra, then feeds them into one shared model alongside text and images. To teach agent skills, the team built test environments for tool use, search and coding, where results are checked by running the work. The model was tested on 33 benchmarks across seven domains. Against five baselines, it ranked first on OfficeQA Pro, MLE-bench Lite, Harvey LAB and SpreadsheetBench 2. It placed second on OSWorld-Verified, WebArena-Verified and DeepResearch Bench II. The authors say it is strong at using documents as evidence, building spreadsheets and doing machine learning tasks. The report also has a naming mismatch: the title says S2.1 while the text says S1.5.
