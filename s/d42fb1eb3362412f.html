Retell credits OpenAI models for powering 100M monthly voice calls

Retell, a company that builds voice agents, uses OpenAI models to help handle about 100 million calls each month. Voice agents are AI programs that talk with people on the phone. According to OpenAI's blog, a model called GPT-6 Astra ranks first on Retell's own benchmark, which is a test used to compare how well voice agents perform. The post also says Retell uses Codex, OpenAI's coding tool, and that this helps the company reach an annual revenue run rate of $1.6 million per employee. A run rate projects yearly income from current earnings. The source gives few other details, but it shows how a small team can use AI tools to serve a very large number of customers.
