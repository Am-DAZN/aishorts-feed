LLM 0.37.2 fixes bug that could leak your OpenAI API key

Simon Willison released version 0.37.2 of LLM, his command-line tool for working with AI models. The update fixes a security problem reported by Daniel de Araujo. LLM lets users connect to other companies' services that work like OpenAI's. Daniel found two cases where your OpenAI API key, a secret password for your account, could be sent to one of those other providers by mistake. One case happens if the key named in the setup was never stored. The other happens if a model set to use the responses option is run with the chat completions option. Users of this feature should update.
