Microsoft Finds Way to Backdoor AI Agents by Editing Few Neurons

Microsoft researchers have found a backdoor method called Lazarus. It rewrites fewer than 10 dormant neurons, the parts of an AI model that rarely activate. No retraining is needed. The model passes standard tests and acts normally until a hidden trigger appears, such as a date passing into 2027. Then an agent with tool or terminal access could download and run an attacker's code. The researchers say such edits can be caught if you compare the model to its original weights, and frontier agents can spot odd changes when asked. But no scan can prove a model is safe, so knowing where a model came from matters. Microsoft Foundry ties open-weight models to their original publishers and runs them in scanned containers. It is also building weight scanning, red-teaming tools and cryptographic model signing.
