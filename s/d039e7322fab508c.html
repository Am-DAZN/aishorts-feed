TAO Scheduler Speeds Up AI Agents by Planning Around Tool Delays

AI agents often switch between two jobs. The AI model thinks on a cluster of GPUs, then waits for outside tools running on regular computer chips. Researchers say current systems ignore whether a tool has finished, so scarce GPU space gets wasted. They also use rough rules to decide which waiting sessions to run and where. The team built TAO, a scheduler that looks at how soon a tool will return, what saved data a GPU already holds, and how many tokens (small chunks of text) a session uses. It then picks and places sessions together using a planning method called dynamic programming. Across 12 tested setups, TAO cut latency by up to 26.8% and time to first token by up to 36.3%. It raised decode throughput by up to 29.5%. These gains are measured against the best existing baseline for each metric.
