Anthropic's IPO video reveals how it runs Claude on four chip types

Anthropic has started its IPO roadshow, and its video shares new details about the business. Co-founder Tom Brown says Claude is trained and run on four chip families: AWS Trainium, Google TPUs, NVIDIA GPUs and AMD GPUs. Brown calls this an unconventional bet, since each chip needs its own software. This year, Anthropic had its Mythos model get Claude running on AMD chips in three days, with almost no human help. Brown also described "compute multipliers," tricks that let the same hardware do more. A 4x multiplier means a model needing 100 units of compute needs only 25. Anthropic says these gains stack and could speed up if Claude finds them itself.
