New AI design lets a model reorder its own layers on the fly

Most language models run their layers in the same fixed order every time. A new paper proposes Library of Layers (LoL), which picks the order of its layers while it works, much like programmers reuse the same building blocks in different orders. It has one setting: the size of a shared library of transformer blocks, the core parts of these models. Changing it moves the model between reusing parameters and using only some of them. When trained on text, LoL performed about as well as three common designs. On sudoku and maze puzzles, it used different layer orders for different solving strategies, and researchers could steer it to use a chosen strategy. It also chose different orders for different languages and scripts. Probes on its routing could tell safe text from unsafe text. The authors say this could make reasoning more efficient and controllable.
