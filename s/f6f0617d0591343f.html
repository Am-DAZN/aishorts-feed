WebAnything Automatically Rebuilds Real Websites as Practice Grounds for AI Agents

AI agents that browse the web need safe copies of websites to train and be tested on. Building these copies by hand takes a lot of work for each site. WebAnything is a new framework that does it automatically from real web addresses. One part explores a site and builds a copy. A separate checker tests it and guides fixes. The team built 244 website copies across 14 areas, with 12,984 accepted tasks. In a blind review, it beat a human-assisted method called WebHarbor, with 12 wins, two ties and no losses. Training the Qwen3.5-9B model on 5,856 recorded interactions raised its success on several web benchmarks, including 13.33 points on WebArena-Verified. This could make training web agents cheaper and easier to repeat. The code is public.
