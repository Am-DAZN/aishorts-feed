Octopus lets AI sub-agents share one memory, boosting search accuracy

Researchers introduced Octopus, a way to train several AI agents that work in parallel using a single model. Most multi-agent systems copy the same memory for each branch and share findings by rewriting text summaries. That wastes computer memory and time. Octopus lets branches share one memory store on the GPU and read each other's results directly. It also trains all branches together and gives each one credit based on how much it helped. Built on the Qwen3.5-4B model, it scored 49.6% on the BrowseComp-Plus web search test, 17.5 points above a single-agent baseline. It also reached 51.2% on OpenResearcher and beat agents up to 250 times larger. Training ran 3.3 times faster, and peak memory use fell 2.8 times.
