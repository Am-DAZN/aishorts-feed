SOLVE Lets AI Agents Steer Robot Arms With Just a Few Key Poses

Researchers have built SOLVE, a way for a large language model (LLM) agent to control a robot arm without any extra training. Instead of issuing constant step-by-step commands, the agent writes a short, ordered list of key arm positions. A motion planner then fills in the movement between them. The agent picks how many positions to use, so it can move fast or work carefully. It also learns from its own attempts by writing down a few rules for each task. SOLVE scored 74.5% on RoboDojo and 84.5% on RoboLab, two robot tests. It costs about $1.7 per episode, 12 times less than earlier agents that control every step. On a real robot, it succeeded in 75 of 85 episodes across 16 new tasks, an 88% success rate.
