Datasette gets a charts plugin that reads every row, not just one page

Simon Willison has released an early alpha of datasette-charts, a plugin for Datasette, a tool for exploring data. He built a first prototype using an AI coding assistant, then turned it into a full plugin. It works on any table or SQL query and suggests chart types that fit the data, shown as small previews. Older plugins like datasette-vega only charted the current page, usually up to 100 rows. This one turns each chart into a SQL query that covers the whole result, even millions of rows, and returns up to 5,000 rows for display. Chart settings are saved in the URL, so charts can be bookmarked or shared. Willison calls it still an alpha.
