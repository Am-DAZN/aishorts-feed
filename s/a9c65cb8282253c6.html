Conference Badge Turned Into a Game Boy Color Player With Gemini's Help

At GitHub Universe, the conference badge is a small computer with a color screen. Simon Willison, who has been hacking on it, met Steve Francia, who used Google's Gemini AI to build a working NES emulator for it. An emulator is software that lets one device act like an old game console. Francia then went further and added emulators for the Game Boy and Game Boy Color. If you have the game file, known as a ROM, you can play titles like The Legend of Zelda: Link's Awakening on the badge. You can flip the badge upside down to use touch buttons built into its body as game controls.
