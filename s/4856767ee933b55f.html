CausalWAM Teaches Robot Models to Act Only on What Causes Actions

World action models (WAMs) are AI systems that learn a hidden picture of a scene. They use it to predict how the scene changes and to choose robot actions. The problem is that only part of a scene actually causes an action. A model trained on demonstrations can mix useful signals with irrelevant ones and still copy the demos well. This paper proposes CWAM, short for Causal WAM. It adds a sparse routing path to the action part of an existing WAM, so actions draw on fewer hidden variables. The prediction goal stays the same. The authors prove that, under this sparsity rule, the action signals depend only on the true action causes. Tests on synthetic data and real robots support the theory and show better success in closed-loop tasks.
