AI Agents Build Machine-Checked Math Library for Inverse Problems

Researchers released AutoIP, a library for the Lean proof assistant, which is software that checks math proofs step by step. AI agents wrote the formal versions of classical regularization theory, a set of methods used to solve inverse problems, along with the math it depends on. The authors say a checked proof only proves the exact statement it was given. So the human job is to confirm each statement means what was intended. The library is organized so a reviewer can compare statements with plain-language versions and never read a proof. The team found the main risks are in the statements, not the proofs. Simple automated tests on statements even exposed a textbook theorem whose condition was stricter than claimed. They invite the inverse problems community to extend the library.
