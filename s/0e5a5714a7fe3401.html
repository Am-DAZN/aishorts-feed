FMT Image Format Decodes Lossless Photos in a Fixed Number of Steps

Learned lossless image codecs make smaller files than classic ones like PNG. But they are slow. A learned codec can take seconds to open a photo that a classic codec opens in milliseconds. The authors say much of that time is spent waiting, not computing. They built FMT, a lossless format that stores an image as a coarse-to-fine tree. Each step of the tree holds values that do not depend on each other. A GPU predicts a whole step at once and decodes it in parallel. So an image of any size needs the same number of sequential steps. Without a neural network, FMT beats NVIDIA's HTJ2K on both size and speed. With a large network, it decodes Kodak photos 9 to 61 times faster than learned codecs on the same A100 GPU, at the same size or smaller.
