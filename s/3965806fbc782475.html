Hard Checks Beat Fancy Scoring When Picking the Best AI Answer

When an AI model writes several possible answers, something has to choose the best one. Common methods rely on the model's own confidence or on another AI acting as judge. These can miss answers that are insecure, unsafe, or break task rules. Researchers propose a scoring system that first applies strict pass-or-fail checks, then blends softer scores into one number per answer. They tested it on secure code, robot plans, coding contests, and question answering. The biggest gains came from combining strict checks with comparing candidates. Safety in code rose by up to 0.28, and joint correctness and safety in question answering rose by up to 0.21. Gains were small or slightly negative where the first answer was already good. The extra layer that tunes the soft checks for each task added no clear benefit. The strict, tool-based checks did the real work.
