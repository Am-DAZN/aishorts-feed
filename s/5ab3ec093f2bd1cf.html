Datasette Lite rewritten to run full Datasette app inside the browser

Simon Willison has released a full rewrite of Datasette Lite. It runs the Python Datasette app directly in a web browser using WebAssembly, Pyodide (a Python engine for browsers) and service workers. He says it now feels almost the same as the real server version. A carefully built URL can load SQLite, CSV or JSON files, pick a Datasette version, use a chosen SQLite version, and install plugins. This makes it easy to share demos, work-in-progress features or bug reproductions without running a web server. Willison already uses it in Datasette development, linking to old and fixed behavior for a pagination bug.
