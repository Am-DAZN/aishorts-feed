VFlash speeds up visual planning for robots by predicting whole shapes at once

Robots and self-driving cars can plan using visual marks like points, boxes and paths, not just words. But today's vision-language models write these out one coordinate number at a time, which gets slow as plans grow richer. VFlash is a new method that predicts all coordinates of a shape in a single step, using a small helper model called a drafter. It adapts to the shape's type and length, from compact boxes to long paths. It trains on annotated shapes and accepts any valid result, instead of copying the older model's exact output. On 2D and 3D robot path tasks, it made fewer errors than step-by-step decoding. Early tests showed about 25 times faster generation for 3D point motion forecasting. A robot model using VFlash plans reached 70.2% average success across four MolmoSpaces task suites, versus 62.6% for the baseline.
