Qistas: A Pre-Registered Plan to Test LLM Fairness Beyond the US, Starting with Iraq

Most tests of fairness in AI language models are written in English and use American social categories. Translating them does not fit other societies well. Researchers propose Qistas, a testing protocol that can be adapted for any country and is first built for Iraq. It checks whether a model treats matched pairs of prompts the same way, refuses some groups more often, relies on stereotypes when a question is unclear, and uses loaded wording for real events. The team set out its hypotheses and analysis plan before running any model. They also released their tools and tested a 58-item seed set. Of 25 template groups, 24 failed at least one check, exposing flaws such as swaps that break Arabic grammar. The authors say these flaws are common in similar benchmarks. No model has been evaluated yet, so this is a plan, not a set of results.
