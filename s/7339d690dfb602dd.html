PostgreSQL 19 Arrives Two Months Late With New Read-Your-Writes Feature

PostgreSQL, a popular open-source database, has released version 19. It usually ships in September, but this year it came two months later. Simon Willison says the delay came mainly from many issues the team had to fix, tied to vulnerabilities reported by AI tools. His favorite new feature is a command called WAIT FOR LSN. Many apps send reads to copy servers called standbys. Those copies can lag behind, so a user may not see a change they just made. With the new command, a standby waits until it has caught up to a saved position in the log before running a query. An optional timeout gives an error if it takes too long. Willison notes Wikipedia built a similar hand-made version for MySQL.
