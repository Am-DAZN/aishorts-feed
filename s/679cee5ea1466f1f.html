Hugging Face blog announces Rumble-2-Flash, an open speech model

Hugging Face has published a blog post about Rumble-2-Flash. The title describes it as an open speech model with 0.5 billion parameters, which are the adjustable values a model learns during training. It is said to support more than 40 languages. "Open" suggests the model can be freely accessed by others. The post text was not available, so details such as who built it, how well it works, and how to use it are not known. Still, a small speech model that covers many languages could make speech tools easier to run and use for more people.
