DeepStress Tests How AI Search Agents Handle Bad Information

AI search agents answer hard questions by looking up documents and reasoning over several steps. But how they cope with poor-quality sources has not been studied much. Bad evidence is rare in standard test sets, so failures are hard to reproduce. DeepStress is a new testing framework that fixes this. It swaps the real search tool for a synthetic one that generates documents for each question. Researchers can set how trustworthy, relevant, and factually correct those documents are. The paper also adds a five-way way of sorting final answers and two new scores, RAS and CoPRAS, which reward cautious behavior and factor in computing cost. Testing 12 systems on HotpotQA and BrowseComp-Plus questions, the team found that several open-weight agents answered confidently even when sources showed clear signs of being unreliable. Many HotpotQA questions were also answered from the model's own memorized knowledge, even when every returned document was wrong.
