New Method Picks Useful Data Features Without Needing Labels

Researchers have proposed LIDFS, a way to choose the most useful features (columns of data) when no labels are available. It flips the data table so each feature acts like a point, then measures how crowded its neighbors are using local intrinsic dimensionality. Features with lower scores are easier to tell apart and rank higher. A second step drops near-duplicate features. The result is one full ranking, so users can pick any number of features without rerunning it. The team tested it on 23 high-dimensional datasets. It ranked first in classification tests and first or tied second in clustering tests. It matched methods that need to know the number of classes and ran faster than its closest rival. Several recent methods failed to beat random selection. Small neighborhood sizes worked best.
