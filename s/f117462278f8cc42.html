FAME-QP Speeds Up Real-Time Robot Control on GPUs

Researchers present FAME-QP, a new solver that runs on graphics chips (GPUs). It handles a type of math problem called a quadratic program, which shows up in model predictive control. That is a method where a robot plans its next moves by predicting what will happen. The solver combines several steps into fewer GPU tasks and replays them quickly using a tool called CUDA graphs. It also picks its own settings by testing the GPU and timing the problem at hand. When the problem changes, it updates only what it needs. In tests, including simulated humanoid and quadrotor (four-propeller drone) control, it responded faster than other GPU solvers. It kept the same accuracy and control quality. Faster solving matters because robots must decide in fractions of a second.
