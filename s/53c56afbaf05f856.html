OpenAI introduces GPT-6 Cyber, a model built to find and fix security flaws

OpenAI has announced GPT-6 Cyber, a model made for cybersecurity work. It is designed to find vulnerabilities that attackers could exploit, which are weak spots in software. It can also help develop fixes for them. OpenAI says the model is trained to stay within authorized scope. In plain terms, it is meant to work only on systems it has permission to test. That matters because tools that can find security holes could also be misused. The announcement focuses on keeping such AI agents aligned with safe, approved use.
