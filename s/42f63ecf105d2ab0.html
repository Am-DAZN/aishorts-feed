MAGE model reads brain signals across multiple timescales

Researchers have built MAGE, an AI model for EEG, the brain signals recorded with sensors on the scalp. Earlier EEG models look at the signal at one fixed time scale. But brain activity changes over both short and long stretches of time. MAGE uses a special attention method to learn from several time scales at once. It also has a trainable part that picks the scale most useful for each input. Tested on seven datasets, MAGE beat existing EEG foundation models, which are large models trained to work across many tasks. It also used far fewer parameters, the internal settings a model learns. The results suggest that different tasks work best at different time scales. The authors say the source code will be released.
