Adding simple statistics helps AI forecasting models when data is scarce

Researchers propose StatPrompt-LLM, a small upgrade to Time-LLM, a model that reuses a large language model to predict time-series data such as electricity use and weather. The new version adds basic dataset statistics to the prompt and a simple linear shortcut that helps track trends. On three benchmarks, it was tested with the full data prefix and with only 10% of it. With 10%, it made smaller errors than Time-LLM, cutting average squared error by 40.2% and average absolute error by 21.4%. With full data, results varied by dataset. The extra parts add some model size and run time. The work suggests that giving these models basic statistical context can help when data is limited.
