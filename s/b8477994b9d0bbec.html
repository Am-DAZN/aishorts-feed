cmHC Fixes How Hyper-Connections Mix Streams in Large AI Models

Hyper-connections let a neural network pass information through several parallel streams instead of one. An earlier method, mHC, keeps this stable by limiting how streams mix, using a set of matrices called the Birkhoff polytope. This paper finds a trade-off. If streams mix too little, they act like separate lanes. If they mix too much, they become hard to tell apart. The authors back this up with theory. They then propose cmHC, which shrinks the allowed set slightly toward its center so streams mix more. It adds no new parameters. A lighter version is used in early layers to avoid over-mixing and keep training stable at large scale. Tests on dense and mixture-of-experts models of various sizes show it works. The team also built faster code for Ascend chips, cutting hyper-connection latency by up to 44.8%.
