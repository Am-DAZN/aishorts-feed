NVIDIA Says Its Vera CPU Runs AI Agents Faster and Uses Less Power

NVIDIA says its new Vera CPU (the main chip that runs everyday computing steps) is built for AI agents. Agents search, query databases and run code, and each step needs a CPU. NVIDIA says that in a 100-megawatt data center comparison, Vera fit 1.6x more agents per watt than the fastest x86 CPU. It was also 2x faster than the most energy-efficient x86 CPU. Early users report gains too. Perplexity ran coding tasks 1.5x faster. Daytona started 1,000 agent sandboxes in 10.8 seconds, versus 88.4 seconds on x86. Power is a key limit for AI data centers, so doing more work per watt matters.
