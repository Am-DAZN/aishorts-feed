PatchScout Helps AI Agents Gather Web Documents on One Theme

Researchers often need large collections of web pages on one topic, spread across many unconnected sites. Current tools either keep digging in one spot or stop too early. A new paper presents PatchScout, a system where several AI agents work together. It treats the web like a foraging ground, where groups of related pages are "patches." The agents decide when to keep searching one patch and when to move on to a new one, all within a fixed budget. On four live-web topics, it found more documents and covered more websites than the baseline methods. In a social science test, it found 102 entities missing from an earlier collection. This could help researchers expand datasets they already have.
