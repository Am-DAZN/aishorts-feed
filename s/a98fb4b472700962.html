New Training Method Helps Lightweight Async RL Match Rival in Early Steps

Many teams now train large language models with asynchronous reinforcement learning. This means the model updates as each answer attempt arrives, which saves time. A recent method called SAO handles this well, but it needs a closed-source value model, which is a helper that scores how good each step is. Researchers built a light version without it, called LiSAO. They found GRPO, a common method, beats LiSAO on reasoning tasks, while LiSAO wins on agentic tasks, where models take many steps. LiSAO also starts slowly because its helper model is not yet trained. The new method, Li2SAO, fixes this. While the helper is untrained, it compares answers within a group to guide learning. Later it switches to single-attempt training. Tests show it matches or beats GRPO early and reaches higher final scores. The code is public.
