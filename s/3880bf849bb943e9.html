Datasette stops Firefox from needlessly prefetching the next page of table rows

Simon Willison noticed that Firefox was quietly loading the next page of a Datasette table whenever someone opened a table page. The cause was an HTTP link header marked rel="next", which Datasette sent with its pages. Firefox treats it as a hint to fetch that page early. Few visitors click "next," so most of this work is wasted. The browser downloads data nobody needs, and the Datasette server must build a full page that gets thrown away. Willison opened issue #3046 to stop sending the header to Firefox for HTML pages. He also found that Firefox has had an open issue about this behavior for 24 years. One early comment links to his own 2002 blog post complaining about it, which he had completely forgotten.
