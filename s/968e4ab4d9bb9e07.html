Datasette Apps now let small apps link to one another

Simon Willison has released datasette-apps 0.4a0, an early alpha version of a Datasette add-on. Datasette Apps are small, sandboxed web apps that live inside Datasette. Sandboxed means they run in a protected space. They work a bit like Claude Artifacts, but they can run SQL queries on your data. The new version adds support for linking. You can point to an app using a #fragment, the part of a web address after the # sign, and the app can read it. Datasette Agent is also told which link types are supported, so it can help write apps that link to each other. For example, one app could show details of a single record, while a separate app searches records and links to each result in the first app.
