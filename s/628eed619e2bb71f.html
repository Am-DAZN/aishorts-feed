curl creator: AI Rust rewrites can't match ongoing bug fixes

Daniel Stenberg, who leads the curl project, says AI coding agents turned 185,000 lines of C code into 340,000 lines of Rust code. He counted them himself. In the same three-plus weeks, the real curl team merged over 300 commits, including a little over 200 bug fixes and a few security fixes. None of the Rust rewrites have those fixes. Stenberg says another month would bring about 200 more fixes. He asks whether the AI-made clones can keep up. His point is that copying code is not the same as maintaining it.
