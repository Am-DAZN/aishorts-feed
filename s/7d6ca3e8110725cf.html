REA Lets Robot 'Brain' and 'Reflexes' Work Together Without Waiting

Big AI models reason well but are too slow and costly to control a robot's every move. Fast policies react quickly but handle new tasks poorly. The new REA system links the two. A slow "brain" plans, a router picks the right policy, and fast "reflex" policies act. The key rule is that no running policy waits on the brain. REA stores how well each policy has worked and checks in with the brain only at set points. On 3,000 test runs across 60 LIBERO-Pro tasks, it hit 95.9% success, versus 94.7% for the best single policy, while using 25% fewer control steps. It also did well on RoboTwin 2.0, BEHAVIOR-1K and a real Unitree G1 humanoid robot.
