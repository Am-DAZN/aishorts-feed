GridForge offers open digital twin and tests for UK power cables

UK power companies collect a lot of sensor data from underground cables. But there is no public dataset, shared model or agreed way to test tools that help plan maintenance. GridForge aims to fill that gap. It is an open-source toolkit with a physics-based heat model built on international standards. It includes a synthetic dataset of 64 cables, covering 320 cable-years. It also has a neural network trained to follow the physics rules, which predicts temperature within 0.148 °C of the reference model. A five-task benchmark compares three baseline methods. Only one task, estimating temperature without a physical sensor, separates the baselines so far. The authors say better baselines are a priority. The code uses the MIT licence and trains in about two minutes, so engineers can check the results themselves.
