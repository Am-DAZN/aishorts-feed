DeepMem Helps Byte-Level AI Models Read Text More Cheaply

Some language models read text one byte at a time instead of using tokens, which are chunks of words. This works for any language, but it is costly because the model handles every byte in full detail. A new paper introduces DeepMem to cut that cost. It shrinks the byte stream into shorter sequences for the main thinking, while extra side data keeps every original byte exactly intact. Memory blocks help process the text, and a decoder later rebuilds the full byte detail. The authors say DeepMem beat a similar byte-level Transformer on FineWeb-Edu and PG19 and had the best average score across the FLORES languages tested. It also did better on the PIQA reasoning test and stayed competitive on code, multiple-choice questions, and resistance to corrupted text.
