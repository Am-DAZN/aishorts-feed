Duopra Teaches Voice AI to Talk Naturally and Finish Tasks

Some voice AI models can chat in real time. They handle interruptions and short replies like "uh-huh" well. But finishing tasks is harder. The AI must call the right tool at the right time and fix its request when the user corrects it. Researchers tested one such setup on a benchmark called Full-Duplex-Bench v3. They found most failures happened before any tool even ran. They built Duopra, a model that learns task execution along with conversation control. It treats a backend system as a tool and sends it a clear, self-contained request. Training has three stages, including reinforcement learning that rewards timely, complete actions. With the same backend, success on the first try rose from 4.7% to 44.7%. Duopra reached 47.7% when calling tools directly and 49.3% with a DeepSeek backend. It also improved three turn-taking scores over the base model.
