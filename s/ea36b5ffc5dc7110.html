LRMoE Speeds Up Training of Large MoE Models on Limited GPU Memory

Mixture-of-Experts (MoE) models split work among many small expert networks, but some experts get far more data than others. This slows training. Past fixes copy popular experts, yet the copies use up scarce GPU memory that is also needed for data buffers. Researchers built LRMoE, a training system that is aware of memory limits. During the backward pass, it estimates which token-expert pairs matter most for updating an expert, and keeps only those within set quotas. It then spreads the kept work evenly across copies of each expert and packs it into smaller messages and computations. On Qwen3-30B-A3B and GLM4.5-106B-A12B, it cut MoE-layer training time to reach fixed loss targets by 21.2 to 44.8 percent compared with SYMI, an existing method.
