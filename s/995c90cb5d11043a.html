Youtu-Parsing-Omni: One 5B Model Parses Documents, Images, Audio and Video

Researchers released Youtu-Parsing-Omni, a single model that turns documents, images, audio and video into structured records. Each record points to where and when the information appears, so AI agents can find and cite evidence. It uses one encoder for every type of input and one shared output format across ten parsing tasks. Video frames can also draw on the sound playing at the same time. The team trains it with a method where the model learns from its own attempts, guided by a reference copy that is updated each round. The 5-billion-parameter model scored 96.96 on OmniDocBench v1.6 and led open-weight models on OmniParsingBench with 75.08, mostly thanks to audio and video. It also did well on charts, chemical structures and sheet music. Code and model weights are public.
