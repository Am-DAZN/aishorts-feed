Greptile uses OpenAI tools to catch bugs beyond code review

Greptile, a company that finds bugs in software code, is using several OpenAI tools to go further than standard code review. According to OpenAI's blog, Greptile uses GPT-6 Astra to test how users move through a product, which are known as user workflows. It uses Daybreak to strengthen security. It also uses Codex to reduce rework, meaning less time spent fixing the same problems twice. The source gives only a short description, so details on results or how each tool works are not provided.
