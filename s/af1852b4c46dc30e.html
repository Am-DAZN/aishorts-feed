Hugging Face Shows Huge 180B AI Model Running on 32GB of RAM

Hugging Face has published a blog post about running very large AI models on limited hardware. According to the title, the post covers a model with 180 billion parameters, which are the numbers a model learns during training. It runs on just 32GB of RAM, about what a high-end home computer has. The post focuses on MoE inference. MoE, or mixture of experts, is a design where only parts of the model work on each task. The work uses the Transformers library. The full text was not available, so details on the method and results are unknown. If it holds up, it could make large models easier to run for more people.
