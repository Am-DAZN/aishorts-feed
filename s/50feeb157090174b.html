New method lets vision-language models create images using shared visual representations

Some AI models can both understand images and generate them, but combining the two skills in one model is hard. The authors of this paper say a key problem is that understanding and generating images use different ways of representing visuals. Their method, called Integral, turns an existing vision-language model into one that does both. It builds a shared visual space for the two skills. One part, Abstraction Fusion, combines layers of information from the model's frozen vision encoder into shared visual tokens. Another part, Block-wise MoT, adds a small generation stream that talks to the main model only at block boundaries. The model keeps its original understanding ability while gaining strong image generation. In controlled tests, sharing the visual representation helped generation learning more than using a separate one, even when image reconstruction quality was similar. This suggests pretrained vision-language models already hold a good base for making images.
