New decision tree learns to ignore outdated data in changing streams

Data streams, like sensor feeds, can change over time. This shift is called concept drift, and it often forces models to be retrained. Researchers introduce Time Neutralising Trees (TNT), a type of decision tree built for this problem. While training, TNT filters out old samples that no longer fit the current state of the stream. If those samples become useful again, TNT brings them back. The team tested TNT and related methods on 24 real and semi-real data streams from the USP DS repository. They report strong evidence that TNT performs best in its class across many kinds of concept drift. The work builds on earlier findings that standard batch learning methods can beat stream methods when data can be stored.
