Video-Coder Trains an AI Agent to Write Code That Guides Video Generation

Video generators look good, but they often struggle with exact layouts, natural motion and control over a scene. Video-Coder takes a different route. It is an AI agent that writes and runs code to build a simple moving 3D scene, called a Draft Video. This draft gives a video generator clear signals about structure and motion. The team built two datasets and a testing environment where the agent can run code, render scenes and see feedback. They trained the agent in two steps, first with examples, then with reinforcement learning, where it learns from rewards. Rewards come from whether the code runs and how the video looks. Over time, the code reward is reduced so the video reward matters more. The team reports gains of about 7 points on PhyGenBench and 24 points on VBench-2.0 for Minimax-H3. The data, models and code are open-source.
