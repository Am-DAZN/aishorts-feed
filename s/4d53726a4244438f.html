WorldLatent Unifies 4D Perception and Generation in One Model

Researchers introduced WorldLatent, a framework that handles both understanding and creating 4D scenes, meaning 3D space that changes over time. Today, tasks like estimating depth and camera position are usually done by separate tools from those that generate video. WorldLatent uses a multimodal VAE, a system that compresses data, to merge appearance, shape and motion into one shared latent space, a compact internal code. Perception and generation then work as two forms of denoising, or cleaning up noisy data, in that same space. One model learns both in a single training loop. Tests on 4D benchmarks showed strong zero-shot 4D perception, meaning no task-specific training, plus coherent generation and controllable editing. The authors say this offers a scalable base for general-purpose spatial intelligence.
