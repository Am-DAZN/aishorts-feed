LandslideFM: One AI Model That Spots and Explains Landslides

Researchers have built LandslideFM, which they call the first single foundation model (a large, general-purpose AI system) for landslide analysis. Most current tools handle only one image task and need lots of labeled examples. LandslideFM learns from a small set of labeled images plus many unlabeled ones. It also marks where landslides are in an image and passes that to a vision-language model, an AI that works with pictures and text, so it can explain what it sees. The team also released LandslideVL, the first benchmark pairing landslide images with text prompts. They report that the model beats general-purpose vision-language models at landslide reasoning and scene analysis. The code is public. This could help with disaster prevention.
