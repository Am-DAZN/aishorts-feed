SnakeTranslate teaches AI to translate speech while it is still being spoken

Simultaneous translation means translating as someone speaks, without waiting for the full sentence. The system must decide when to wait for more words and when to write out a translation. Normal translation datasets do not show those decisions. Researchers built SnakeTranslate to learn them anyway, using only regular paired texts. It is trained first on these paired texts, then refined by learning from its own translations. In tests on three benchmarks, their 4B model (4 billion parameters) gave better quality for the same delay than other streaming methods using the same base model. It also did well against larger translation models when delays were low or moderate. At higher delays, it still lagged on one benchmark, WMT24++.
