AWS Releases Official Local Emulator Built by Swarm of AI Agents

Amazon Web Services has released aws-emulator, an official tool that lets developers test against a local copy of many AWS services. They no longer need a paid account to do it. The tool is written in Rust and was built by a large group of AI agents, with 29,684 commits (saved code changes) in the first three weeks. Swami Sivasubramanian explained how it came to be in a guest post on Werner Vogels' blog. For now, it needs Docker, a tool for running software in packages, on macOS and Windows. Developer Simon Willison hopes AWS will later offer a single downloadable file that works in test suites across other languages and platforms.
