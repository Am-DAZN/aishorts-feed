Go Proverb: A Little Copying Beats a Little Dependency

Simon Willison shared a short quote from the Go Proverbs, a set of sayings about the Go programming language. It reads, "A little copying is better than a little dependency." In plain terms, a dependency means relying on someone else's code. The saying suggests that copying a small piece of code into your own project can be better than pulling in an outside package just for that bit. The source gives no more detail, but the idea is that fewer outside links can make software simpler.
