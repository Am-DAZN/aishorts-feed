Mod_wsgi creator builds Muru, an AI-assisted Rust server for Python apps

Graham Dumpleton started mod_wsgi, a tool for running Python web apps, 20 years ago. Now he is building Muru, a new server written in Rust with help from AI. It aims to give the best tools for running Python apps, both while developing and in production. It supports the two main Python web standards, WSGI and ASGI. Dumpleton is publishing detailed posts as he works, with 18 so far in three weeks. Topics include HTTPS in development, Kubernetes, scaling to zero and a debugging toolbar. In one post he says the AI does much of the surface work, but he still decides what is not good enough yet. He says his 20 years of mistakes with mod_wsgi help with that.
