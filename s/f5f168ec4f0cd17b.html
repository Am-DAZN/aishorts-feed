Why AI agents make tracking data lineage a security must

A sponsored report from MIT Technology Review's custom content arm says companies need a new approach to AI security. It gives an example: one AI agent gathers pricing data from restricted and archived sources, and a second agent uses it to draft a proposal. No human checks either step, so confidential data slips in and no one can trace how. The report says the real problem is data visibility, not a single tool. Data is constantly copied, summarized and reused. It argues that security built only around apps, networks or devices is no longer enough. Teams need data lineage, meaning a record of where data came from and where it went, to keep control and trust across human and AI workflows.
