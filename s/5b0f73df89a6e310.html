Amplitude uses OpenAI to ship product fixes in 1–2 days

Amplitude, a company that makes product analytics software, has built an AI agent called Wave. It runs mainly on OpenAI models. Wave works on its own to spot what the team should build next. It then helps teams make those changes using coding agents, which are AI tools that write software code. After the change goes live, Wave measures how well it worked. According to OpenAI, this lets Amplitude ship product improvements in one to two days. It shows how companies are using AI to speed up the full loop of finding problems, fixing them, and checking results.
