SketchDirector Draws Complex Scenes From Text Using AI Agents

Most AI sketch tools work from a reference image and handle only single objects or simple scenes. SketchDirector is a new system that draws a full scene from a text prompt alone. It copies how a person sketches. First, a large language model splits the scene into separate objects, each drawn with Bézier curves, which are smooth lines that can be edited. Next, an AI agent plans where each object goes and places it, learning from a memory that improves as it works. Last, a diffusion model, a kind of image generator, adds detail while keeping the shapes intact. The team also released MCSketch8K, a dataset of editable vector drawings and scene layouts. They report that the system beats current methods on meaning and layout quality.
