New Looped Transformer Design Cuts Cost of Reusing Layers

Looped Transformers reuse the same layers several times to get more power from a small model. The catch is that they run slower. This paper introduces Mixture-of-Loops Transformer, or MoLT, which lets each loop selectively reuse stored keys and values (the model's short-term memory) from earlier loops. A U-shaped version, U-MoLT, builds that memory separately from making predictions and skips work it does not need, without changing the output. In pretraining on 400B tokens, U-MoLT beat OLMo3 on 700M, 1.5B and 3B mixture-of-experts models. It reached 1.7x token efficiency at 700M. When applied to Qwen3.5-0.8B-Base, it lowered loss on all 11 domains. At inference, one variant matched OLMo3's speed on a roughly 113M model. Code is public.
