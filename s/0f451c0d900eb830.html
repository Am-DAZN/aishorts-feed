WikiTrace Lets AI Agents Check Their Memories Against the Evidence

AI agents can learn from past tasks by saving short lessons. But these lessons can backfire. An agent may follow a wrong lesson, or misread a good one, and then fail a task it could have solved without any memory. The problem is that lessons are saved without the original records, so the agent cannot check them. A new system called WikiTrace fixes this. It stores each lesson with a summary of why the past task worked or failed, plus the full record of that task. When a lesson is unclear, clashes with another, or comes from a failure, the agent follows the links back to the evidence and fills in details or corrects the lesson before acting. Tested on five agent benchmarks, WikiTrace beat existing memory methods and a baseline given the same lessons alone. It also reduced memory-caused failures. The code is public.
