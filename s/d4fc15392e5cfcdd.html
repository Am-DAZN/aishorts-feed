Webframe runs web pages like programs, and Simon Willison tests it

Webframe is a small project by Jeff Lindsay. You point it at a web address or file, and it runs the page in a hidden browser window. Anything the page logs goes to standard output, and any errors go to standard error. It is written in Go and uses the system's own browser engine on Mac, Linux and Windows, so it does not carry its own browser. Simon Willison says it resembles his shot-scraper tool, but in a smaller package that does not need Playwright, a browser automation tool. He asked Claude Opus 5.5 to try it out, build a few prototypes, and write a report on how well it works as a web scraper and as a sandbox, meaning a safe space to run code.
