Customer Reviews Could Help Stores Decide Which Stock Matters Most

Online stores sort their inventory to decide which items need the most attention. The usual method, called ABC analysis, looks mainly at yearly sales value. Newer methods add more factors, but they still use only numbers and ignore text like customer reviews. This paper proposes using a large language model (LLM, an AI that reads and writes text) to turn reviews into numbers. It uses vector embeddings, which are number codes for the meaning of text, along with criteria written by the LLM. These new features go into an existing multi-criteria ranking method, the Hadi-Vencheh model. In tests, adding customer sentiment changed how some items were ranked. The authors say this shows that unstructured data can improve how stores prioritize their inventory.
