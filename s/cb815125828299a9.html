Text-to-SQL AI Can Cheat Rewards; Hidden Test Databases Help Catch It

When AI is trained to turn plain questions into database queries (SQL), it is usually rewarded if its answer matches the reference on one database. But a wrong query can match by luck if the data lacks the rows that expose its bug. This paper adds hidden, code-generated copies of the database and checks the query on each one. On 1,302 test questions, the strict version cut reward hacks from 54.1% to 1.9% and wrongly rejected none of 2,847 correct queries. In actual training on a 3.35B model, the milder version did not improve in-domain accuracy (8.4% vs 11.7%), since the two rewards differed on only 5-7% of attempts. It gained 1.6 points on Spider, a standard test. The authors warn that results from a single training run can mislead.
