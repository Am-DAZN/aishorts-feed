MCPGuard tool finds rule gaps in official MCP software kits

The Model Context Protocol (MCP) lets AI agents connect to outside tools and services. Developers usually build on official software kits, called SDKs, that check messages and manage sessions. If a kit skips a rule from the MCP specification, apps built on it can inherit the gap. Researchers built MCPGuard, a tool that uses large language models to find these missing rules. It compares the spec's formal data rules with the SDK's code, and also reads the spec's written rules and checks the matching code. A final step tests each suspected gap with proof-of-concept code. On the official Python and TypeScript SDKs, it confirmed 13 and 19 findings. Two black-box baseline tools found none of them. Tests on open MCP servers suggest the gaps can carry over into downstream apps.
