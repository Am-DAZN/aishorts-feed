Russian AI-Text Detectors Disagree Even When Every Text Has the Same Origin

Tools that guess whether a text was written by AI are used where a wrong call can hurt the author. This study tested them on Russian texts. The team built a set of 1,882 documents, both machine-written and archival human-written. In the machine texts, the same model wrote for the same task, and only the task wording changed. Four detection methods then scored the texts. Changing the task shifted all four scores, but not the same way. Three said the text looked less machine-made, while one, a judge model, said the opposite. Other checks were just as troubling. A baseline that used only the source label got a near-perfect score on most splits. Removing emphasis markers flipped a confident machine verdict to human, though the text was otherwise identical. The authors conclude that scores reflect how data was collected, formatted and processed, not just a text's true origin.
