MedicalRSI Lets Medical AI Agents Learn How to Improve Themselves

Most medical AI agents stay fixed after deployment, so the same mistakes can repeat across patients. Existing self-improvement methods learn from an agent's own experience, but the way they improve never changes. A new paper proposes MedicalRSI to fix this. One model plays two roles. The Solver is the medical agent. The Improver studies the Solver's failures and writes a harness, a set of guidance and tools for clinical tasks. Each harness is rewarded by how much it helps compared with having none. Both roles train together, so the Improver keeps targeting problems the Solver still gets wrong. Across several benchmarks and language models, MedicalRSI beat existing self-improvement methods. It also worked on unseen workflows, new models and new databases. The authors see it as a step toward medical agents that keep improving.
