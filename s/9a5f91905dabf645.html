SQLite's rsync tool copies databases without needing extra disk space

sqlite3_rsync is a SQLite tool that copies a database to another machine over an SSH connection. It first appeared as experimental in October 2024 and was improved in May 2025. Simon Willison highlights its best feature. The usual ways to snapshot a database, the backup API or VACUUM INTO, need enough free disk space for a full duplicate. This tool does not. It also updates an existing copy without sending the whole database again. The copy sends short fingerprints of data chunks, and the original replies only with the parts that differ. If the two copies are very different, the extra network use is a few percent at most. This helps small servers that are already over half full.
