New method lets speaker-tracking AI handle any number of voices in long meetings

Diarization means working out who spoke when in a recording. Many modern neural systems, like Streaming Sortformer and Nemotron-3, have a fixed number of speaker slots, so they fail when more people talk than slots exist. This paper, called eDIAR, removes that limit without retraining the models. Once every slot is used, it groups voice fingerprints (called embeddings) inside one slot using an algorithm named e-means. Re-grouping stays within a short window, so the cost of each update does not grow as the meeting gets longer. On meetings up to an hour, it stays far more accurate than Streaming Sortformer, which piles up errors. The authors say e-means also matches the quality of the classic k-means method several times faster, and it can link speakers across large archives of recordings.
