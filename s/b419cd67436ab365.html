New AI Attacker Learns From Target Model to Find Its Weak Spots

Researchers have built RL-ATTACK, a tool that tests how easily large language models can be tricked by small changes to their input. It works in a black-box setting, meaning the attacker cannot see inside the model. Older methods guess at changes using outside knowledge. This one uses reinforcement learning, a trial-and-error training method, to learn from the target model's replies. On a language reasoning task, it cut the model's accuracy to 2% within 20 queries. On generative question-answering models, it beat an untrained attacker every time and won 4 of 6 settings against a strong baseline. The authors say finding such weak spots can help make models safer. They also found no single reward design or training setup worked best everywhere. The code is public.
