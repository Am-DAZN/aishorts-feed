New benchmark tests how well AI coding agents can build 3D objects, scenes and worlds

Researchers released Frontier3DBench, a test for AI coding agents that write programs to create 3D content. It has 145 tasks in 9 categories, covering single objects, full scenes and interactive open worlds. It scores how things look, how they are built and how they behave. The team tried 11 model and tool setups. GPT-6.1-sol had the best overall score, 66.02 out of 100. GPT-6-astra was best at building interactive worlds. All setups did worse when copying a reference than when generating from text. In worlds, single mechanisms scored 83.08 on average, but motion clearance scored 20.82 and multi-step workflows 30.26. Copying exact details and finishing complete activities remain the main weak spots.
