OpenAI launches program to work with utilities on grid reliability

OpenAI has announced the Grid Protectors Program. It will work with electric utilities, the companies that deliver power to homes and businesses. The goal is to help future compute campuses, which are large sites packed with computers that run AI, support the reliability of the power grid. The program also aims to protect what consumers pay for electricity. AI data centers use a lot of power, so people worry they could strain the grid and push up bills. The announcement says little beyond this, so details on how the program will work are not yet clear.
