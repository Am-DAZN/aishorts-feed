Coding agents teach two robot hands to play piano without demonstrations

Teaching robot hands fine skills is hard because good demonstration data is scarce. Copying human video is imprecise, remote control gives no sense of touch, and wearable exoskeletons are hard to scale. PyRUA-Dex takes a different path. Coding agents write programs that control the robot, with no demonstrations needed. Several agents first explore in parallel to find skills and ways to combine them. Another agent then condenses the successful attempts into a skill library and one program. That program is later improved using randomized layouts so it works more reliably and runs faster. In simulation, it scored 72.9 on Bench2Dex and reached 81.0% success on DexJoCo, ahead of every trained policy on both tests. On a real robot with two 22-joint hands, it played piano and wrote calligraphy. Learning a new piece from sheet music took as little as 30 minutes.
