UniRestorer++ Scales One Model to Fix Many Image Problems

Researchers present UniRestorer++, a single model that cleans up images hurt by many kinds of damage, such as noise or blur. Simply making these models bigger soon stops helping. Models that specialize in one damage type can fail when they guess the damage wrong on unfamiliar or real-world photos. The new method sorts damage types into groups that get finer step by step, and adds expert parts for each group. It picks a path through these groups and decides how fine-grained to be, which balances skill and reliability. It can also treat different parts of an image differently. The team built CDD-50, a test set with 50 damage types, from one problem to five at once. Results show steady gains as the model grows, and larger gains on unfamiliar and real-world images than a standard expert-based approach. The code is public.
