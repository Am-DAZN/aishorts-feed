ChatAtom lets users run molecular simulations by simply asking in plain language

Researchers have built ChatAtom, a system of several AI agents that runs molecular dynamics simulations. These simulations track how atoms move to predict how materials behave. Normally, an expert must design the study, write code, run it and analyze results with different tools. With ChatAtom, a user types a request in plain language. One agent plans the study. Others write and double-check the simulation and visualization scripts before they run. Another sends jobs to remote computers, and a final agent explains the results. A browser page shows live data and images as the simulation runs. New abilities can be added without changing the agents. The team tested it on code-writing benchmarks, a crack-spreading study and a closed-loop campaign. They say it makes advanced simulation easier to use.
