MORSE Lets AI Search Research Papers to Fix Its Own Video Memory

Streaming video AI must decide what to remember as frames arrive, before it knows what question will be asked. MORSE is a new framework that improves this memory setup automatically. It looks at mistakes that keep repeating across videos and groups them by cause. Then it searches papers, model cards and code for methods or ready-made vision models that could fix them. It also adjusts how the system stores and retrieves what those tools find. Later, it looks for faster versions that keep the gains. On three streaming video tests, MORSE had the highest accuracy among systems using the same frozen model. On OVO-Bench, its Qwen3-VL-8B setup scored 75.1% accuracy, 3.1 points above the next best, and answered in 0.30 seconds on average.
