Simple Medication Tables Beat Patient Lookups in AI Prescription Prediction

Researchers studied how AI can predict which medication classes a hospital patient will need, using electronic health records. Many current systems fetch records of similar past patients and ask a large language model (LLM) to guess the medicines. The authors say this is an indirect fit, since the answer is a set of labels from a fixed list. They propose a simpler source: a table showing which medications usually go with which conditions, built from past admissions. Swapping this table into an existing system called PACERAG raised the F1 score (a measure of accuracy) from 0.303 to 0.338. This was tested on 1,004 held-out MIMIC IV admissions. It needed no extra LLM calls and no patient index at prediction time. Even a basic ranking from the table, without an LLM, scored 0.248. The authors say population statistics can be more efficient and easier to audit than patient lookups.
