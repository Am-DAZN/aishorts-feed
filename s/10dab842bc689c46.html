Simon Willison ships LLM 0.37 with new models and cheaper default

Simon Willison has released version 0.37 of LLM, his command-line tool and Python library for working with AI models. It bundles about two months of features and fixes. He added two new models, gpt-6.1-sol and gpt-6.1-terra, and a new command to set up extra models that use OpenAI-style connections. The default model is now gpt-6-luna, which costs half as much as the old default. Embeddings, which turn content into numbers for search and comparison, now handle different types of binary files. That helps with models like Gemini Embedding 2, which works with text, audio, images and video. Willison also says AI-assisted code contributions have not overwhelmed him. Twelve authors contributed fixes, almost all with AI help. He treats them like bug reports with examples, and uses AI to sort the most useful ones.
