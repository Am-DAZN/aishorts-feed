Simulating Events Builds Coherent Cyber Threat Knowledge Graphs, But Testing Them Is Hard

Researchers studied a new way to make training data shaped like knowledge graphs, which are maps of things and how they connect. Instead of having a language model write each piece directly, they run a simulation. AI agents suggest actions, and a fixed rule-based referee checks them against a world model. A link is added only if the event really happens, so the graph stays consistent. They built this for cyber threat intelligence in the STIX 2.1 standard, using three engines. They prove that links never point to missing items and that each link has a cause. They also warn that common checks of graph quality fail here. A random graph with similar structure can fool them. Four tests rewarded trivial patterns instead of real coherence. The authors explain why and list what a fair benchmark needs.
