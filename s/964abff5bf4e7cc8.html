New Benchmark Tests Whether AI Coding Agents Can Find Bugs on Their Own

Researchers released SpecEngineeringBench, a test for AI coding agents. Most older tests tell the agent what to check or where to look. This one does not. The agent must work out what to test from the requirements, write the tests, and use the results to find hidden bugs. It has 100 cases from 78 open-source Python projects, each with several known bugs. Seven top coding agents were tested. Their tests usually ran fine, with a 91.47% pass rate on the fixed code, but only 26.36% of tests caught the bugs. Pinpointing the bug also got harder in finer detail: recall fell from 78.11% for files to 51.29% for functions. Writing new tests did help a little over using only the existing tests. The results show that valid tests do not guarantee bugs get found.
