New Quaternion-Based Networks Spot Rotated Objects With Fewer Parameters

Researchers introduced Quaternion Approximate Networks, or QUAN, a new way to build image-recognition models that handle rotation well. Quaternions are a type of math used to describe 3D rotation. Earlier quaternion networks tried to work fully in that math. QUAN instead approximates it using ordinary real-number operations, which keeps the geometry while running efficiently on custom GPU code. The team also added a training-stability method called Independent Quaternion Batch Normalization and applied quaternion ideas to attention. Tests covered image classification, object detection and robotic perception. QUAN reached higher accuracy with fewer parameters and faster training than standard and quaternion models. In detection, it was more parameter-efficient and handled rotation better than standard CNNs. The authors say it could suit robots with limited computing power.
