Datasette Agent adds a prompt box to the Datasette homepage

Simon Willison has released version 0.6a0 of datasette-agent, a plugin for Datasette. The plugin lets people ask questions about their data in plain language. This early test release collects a number of small fixes. The main change is that an agent prompt now appears directly on the Datasette homepage. Users can also mention specific tables and saved queries by typing a hash symbol before the name. That makes it easier to point the agent at the right data without leaving the front page.
