Small AI Model Switches to Higher Precision Only When Unsure

Researchers tested a way to run a small AI model, Qwen3-0.6B, with less memory traffic. The model stores its numbers in 8 bits but normally reads only the top 4 bits. When its output looks uncertain, it redoes that step using all 8 bits. On 150 math problems from GSM8K, always using 8 bits scored 64.0% and always using 4 bits scored 55.3%. The uncertainty-based switch scored 62.7% while reading 0.87 of the bytes of the full 8-bit setup. But the differences were small, so the live results could not clearly separate the switch from either extreme. Quantization, which means shrinking numbers to fewer bits, was simulated. A different method, verified speculation, matched the full output at similar cost in the same model. Several tests were not run, including a second model.
