Datasette 1.0a43 adds streaming exports, security fixes and smoother page transitions

Simon Willison has released datasette 1.0a43, a new test version of his tool for exploring and sharing data. The 1.0 milestone is now 53% complete. The biggest change is streaming support for output renderers. The built-in CSV and TSV exports now use it, and plugins can stream every row in a table at once. Two security fixes are included. One fixed a bug where private stored queries could show their title and SQL, though not be run. The release also adds a copy button component, pretty-printed JSON on row pages and dozens of bug fixes. Willison is most excited about a small CSS change that adds view transitions between pages, so browsing feels more like a single-page app. It works in Safari and Chrome now, and Firefox support is expected in version 162.
