WebArena-Pro tests AI web agents on audio, video and 20 apps

Researchers have released WebArena-Pro, a new test for AI agents that do tasks in a web browser. It has 300 tasks across 20 self-hosted web apps in six categories. Older reproducible tests cover few apps and mostly use text and images. Live tests cover more sites, but pages change between runs, so results are not repeatable. WebArena-Pro treats audio and video as core inputs, with special actions to pull information from them. Each task runs in isolation, so tests can be repeated and run in parallel. Humans checked every task before release. The best agents, Codex with GPT 6.1 Sol and Claude Code with Claude Opus 5.5, scored 62.3%. OpenCode with Kimi 3.1 Pro reached 60.7%. The top GenericAgent setups scored 30.3%. The gap shows web agents still have a long way to go.
