Developer uses Claude Code to build a tool that finds a mystery beep

Simon Willison had a beeping noise coming from a room full of unpacked boxes. Instead of digging through them, he had Claude Code build Beep Locator, a tool that finds a sound's source using several devices placed around the room. Each device listens through its microphone, and devices play chirps to each other to estimate where they sit. The tool drew on a 2007 research paper called BeepBeep about measuring distance with sound. It placed the beep within about 40cm. Willison then searched that pile of boxes and found an old carbon monoxide detector that needed new batteries.
