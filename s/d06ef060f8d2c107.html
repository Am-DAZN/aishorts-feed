ToolSpace builds tougher training worlds for AI agents that use many tools

AI agents often have to chain many tools together to finish long jobs. Current ways of building practice environments start with made-up data and then invent tools around it. That can leave tool setups unlike real ones. ToolSpace flips the order. It studies records of real tool services and agent runs to see which tools depend on each other, using fixed rules instead of an AI's opinion. It groups tools into environments, then builds tasks from chains of calls and keeps only those that replay successfully. Harder test versions it produced cut seven top models' scores by up to 38.2 points. Training with it lifted Qwen3.6-35B-A3B from 23.0 to 41.0 on average, and GLM-5.2 from 44.6 to 56.6, matching Claude Opus 5. Results kept improving as data and environments grew.
