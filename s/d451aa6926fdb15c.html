Discrete image tokens can now match continuous ones at understanding pictures

AI models can turn images into discrete tokens, like words in a language. This lets one model handle text and images the same way. Many researchers thought this process always loses meaning, so continuous image representations would stay better. This paper questions that idea. The authors find that rounding error is not a good predictor of quality. What matters more is how many bits the token codes carry. Existing methods stop improving as more codebooks are added. The team proposes Factorized Vector Quantization, which splits an image feature into several views and encodes each with its own codebook. It keeps improving with more bits and matches continuous representations on understanding tasks. It beats UniAR by 22.8% and Emu3-Chat by 59.2% on a nine-metric average. It is also the first discrete model competitive with Qwen3-VL, including on fine-grained text reading. Code and models are public.
