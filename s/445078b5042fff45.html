PhysInsert Adds Objects to Images With Realistic Lighting and Pose

Researchers have built PhysInsert, a method for placing a reference object into a new scene so it looks real. Many current tools copy an object's look but miss how it should be lit or posed. They also ignore how the object changes the scene, such as shadows. To fix this, the team made a dataset called Insert World, using Blender-rendered image pairs across different viewpoints and lighting. The model uses a 3D geometry guide, plus image and text inputs, to place objects consistently. It also learns where the object sits and how the surroundings change. The team also created PhysInsert-Bench, a test set with cases that need lighting and pose changes. Tests on that benchmark and on DreamBooth showed better image quality. A user study found more accurate placement and more believable lighting, perspective and pose.
