LoRAWeaver Picks the Right AI Adapter Without Any Extra Training

Updating a large language model from scratch is costly. A cheaper option is LoRA, which adds small add-on modules called adapters for each task. But as adapters pile up, choosing the right one for a given question gets hard. Many current routing methods must be retrained whenever a new adapter arrives. This paper proposes LoRAWeaver, which needs no training. It compares how each adapter represents a query with a profile of each task, using cosine similarity, a measure of how closely two directions match. Tests on LLaMA-2-7B and LLaMA-2-13B used 48 FLAN-v2 tasks plus unfamiliar tasks. The method beat other training-free approaches across tasks and came close to a trained retrieval encoder. This could make it easier to add new adapters without rebuilding a router.
