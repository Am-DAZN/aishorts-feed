New ChartInt test shows AI struggles to code interactive charts

Researchers have built ChartInt, a new test for AI models that turn chart images into code. Earlier tests only looked at static charts, which just need to look right. Interactive charts must also behave right, such as showing a tooltip (a small pop-up label) when you hover over a bar. ChartInt has 2,779 annotated examples covering hover, highlight and tooltips. It also includes editing tasks like updating data, changing styles and copying one chart's style to another. To make testing fair, the team sets target chart states in advance and triggers user actions the same way each time. Results show current multimodal models do well on static charts but drop sharply on interactive ones. The authors say this shows the need for tests that check interaction.
