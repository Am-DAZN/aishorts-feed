L3G-World builds endless, consistent virtual worlds in real time

Interactive world models create video that responds to a user's moves, like walking through a scene. The hard part is staying consistent over a long trip, so a place looks the same when you return. Older methods keep growing memory as the video gets longer, and they slow down. This paper introduces L3G-World, which stores the scene as a compact set of 3D blobs called Gaussians. Memory grows with the size of the world, not the length of the video. Each blob also holds a compressed image feature, so the memory can be drawn straight into the video model without an extra encoding step. The authors report top generation quality and spatial consistency. Against the most efficient earlier 3D-memory methods, they report up to 38.6 times fewer 3D elements, 3.2 times faster memory updates and 359 times faster memory rendering. This allows real-time generation at 9 frames per second.
