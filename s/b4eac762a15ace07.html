NVIDIA Donates OpenShell Agent Security Tool to Cloud Native Computing Foundation

NVIDIA is giving OpenShell, an open source tool for securing and controlling AI agents, to the Cloud Native Computing Foundation (CNCF). The announcement came at KubeCon, a conference for Kubernetes users. Kubernetes is the system that manages how applications run across many computers. OpenShell lets organizations set rules for what agents can do, such as which tools they use. NVIDIA says hundreds of organizations already use it. NVIDIA is also contributing to Agent Substrate, a Google-led project that runs long-lived agents on Kubernetes and frees up computing power when agents are idle. It also announced new tools for managing GPU infrastructure in AI factories.
