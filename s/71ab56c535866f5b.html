AI Agent Lets Plant Staff Manage Maintenance Work Orders by Chatting

Researchers built an AI tool called CodeReAct agent to help with maintenance of industrial equipment. Workers type plain-language requests. The agent then summarizes the status of equipment, pulls out useful knowledge and recommends work orders, which are repair or upkeep tasks. It works in a loop: it thinks, takes an action, then checks the result, much like a person solving a problem. In the action step, it writes code on its own, so no one has to code by hand. The team tested it on chiller maintenance, which are cooling machines. The agent studied several years of work orders and flagged alerts and anomalies. The authors say it can pull insights from data and support decisions, with less need for data scientists. They add that the approach could apply to other maintenance settings too.
