Simon Willison tests a SQLite number parser in C versus Rust

Developer Simon Willison used Claude to explore a small SQLite add-on called parse_number(). It turns text like -$1,234.56 or 12.5% into real numbers that can be summed and sorted. Claude built versions in C and Rust. The C file was tiny at 14 KB, while the Rust ones were about 300 KB. But the first C version was slower, because Rust's number-reading code was twice as fast as C's standard one. Willison then asked Claude to write a custom C parser. It beat both Rust versions, taking 19 ns per row on mixed data versus 41 to 46 ns for Rust. Claude also wrote up the work as a research report.
