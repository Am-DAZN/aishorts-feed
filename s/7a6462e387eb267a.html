OpenAI shares how iFood uses coding agents across 15,000 repositories

OpenAI published a blog post about how iFood uses coding agents at large scale. Coding agents are AI tools that can write and change software code with little human help. According to the title, iFood runs them across 15,000 repositories, which are the folders where software projects and their code are stored. The full text was not available, so details such as results, methods or tools are not known. The title suggests the post is a case study on using AI coding tools across a very large body of code.
