CohortFlow Agent Fixes Patient Group Criteria Without Redoing All Its Work

Researchers built CohortFlow, an AI agent that helps pick groups of patients, called cohorts, for clinical studies. Criteria for who qualifies often change. Usually the agent would start over each time. CohortFlow instead updates only the part that changed. It tracks which steps depend on each other, so it redoes only the affected steps and keeps the rest. In tests on 100 scenarios built from clinical-trial criteria, it matched full redoing on accuracy, 77.0% versus 76.4%. That gap is not statistically significant. It cut correction time by 64.8% after a task finished and 44.3% during one, and used 38.1% fewer model calls. A smaller test on MIMIC, a medical dataset, ran all 13 cohort states successfully. The work suggests faster, cheaper edits to patient selection.
