New RL Method Handles Problems That Run Both Forward and Backward

Reinforcement learning (RL) is a way for software to learn by trial and error. Most RL methods assume a problem moves forward in time from a starting point. But some real problems, such as those in finance and network systems, also have a backward part. Standard methods cannot model them. This paper defines a new problem type called Forward-Backward Markov Decision Processes. The authors build a theory to describe the best solutions and a general template for adapting existing RL methods. They also present an algorithm called FB-MOAC, which the authors say is guaranteed to converge. They tested it on mathematical finance and mobile resource management tasks. The authors report it beat current leading methods across several measures.
