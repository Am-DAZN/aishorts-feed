Datasette Apps 0.3a0 improves how AI agents build and manage apps

Simon Willison released an early alpha version of datasette-apps, a plugin that lets people host and edit custom HTML apps inside Datasette, a tool for exploring data. Apps can be made by hand, but it is easier to build them with a language model through Datasette Agent. This update makes that link smoother. Users can now tag an app in an agent chat by typing #, and it suggests apps they are allowed to view. New tools let the agent control which saved queries an app may run. If a query can write data, the user must approve it first. App creation also checks that each saved query exists and is viewable. Finally, "View app" buttons and # links now open apps full screen in the agent panel.
