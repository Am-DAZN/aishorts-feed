Simon Willison adds tag browsing to his collection of 244 coded tools

Developer Simon Willison wanted a better way to browse his growing set of vibe-coded tools, now at 244 and counting. Vibe coding means building software by describing what you want to an AI. He used leftover credits for an AI model he calls Fable 5.2 to analyze each tool's code with tree-sitter, a program that reads code structure. It found which JavaScript features, code libraries, and web services each tool uses. The tools.simonwillison.net homepage now shows tag clouds for each of those groups, so visitors can browse by tag.
