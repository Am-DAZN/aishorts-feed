OpenAI Builds Pando, a Git Backend Made for Codex-Scale Coding

OpenAI has written about Pando, a new backend it built for Git, the popular tool developers use to track changes to code. Pando works with Git, so existing workflows can keep running. OpenAI says it was designed for the amount of development that Codex, its AI coding tool, makes possible. The short description does not give technical details or performance numbers. It points to a growing problem: when AI helps write far more code, the systems that store and manage that code may need to be rebuilt to keep up.
