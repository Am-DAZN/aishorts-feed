Datasette gets new plugin for streaming Apache Arrow data exports

Simon Willison has released datasette-arrows 0.1a0, an early test plugin for Datasette, his tool for exploring and sharing data. Datasette core can already stream CSV and TSV files, so people can export millions of rows without loading everything into memory. The latest Datasette alpha, 1.0a43, lets plugins add other streaming export formats. Willison says he never ships a new plugin feature without a plugin that uses it. This plugin adds the Apache Arrow streaming format. He says an AI model, Claude Fable 5.2, suggested the format and built the plugin almost in one go. After installing it, the export dialog shows a new Arrow option. Grouping of streaming formats in the dialog is coming in the next alpha.
