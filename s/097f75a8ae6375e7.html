DepThink adds linked tokens to speed up multimodal AI models

Some AI models improve their answers by looping through the same layers several times. This helps reasoning, but it is slow. Other models add extra learnable tokens, small slots that help in a single pass. These are fast, but they often repeat the same information. Researchers now propose DepThink, which adds a set of residual tokens in one forward pass. A light learned link between them lets each token pick up what earlier ones missed. The authors also give a mathematical proof that this reaches more directions than standard learnable tokens. They tested it on multimodal retrieval and generation, using models from 2B to 30B-A3B in size. DepThink beat other token methods and matched or beat looped models. It also trained up to 11.9 times faster and ran up to 4.3 times faster than looped designs.
