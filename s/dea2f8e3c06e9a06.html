Datasette charting plugin now lets you ask a chat agent for charts

Simon Willison has released datasette-charts 0.2a0, an early test version of his charting plugin for Datasette, a tool for exploring data. The plugin launched just a day earlier. Now it works with Datasette Agent, a chat helper. You can ask the chat for a chart, and it builds one using the same chart tools the plugin already has. In a demo, he asks for sqlite-utils downloads over time. A chart appears inside the chat. He can open it in a chart builder panel next to the table page. When he switches the panel to a chart of Datasette downloads and asks what it shows, the agent notices the change and describes the new chart. A demo site lets you sign in with GitHub and try it.
