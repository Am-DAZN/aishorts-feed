Blogger Says AI Can Now Build Games That Are Actually Fun

Developer Simon Willison says October 2026 is a turning point for "vibe coding" games, where you describe a game to an AI and let it write the code. He credits Claude Opus 5.5 for better 3D modeling, music and, most surprisingly, game design. When he told it to "Make it a LOT more fun," it did. In recent weeks he built four browser games he truly enjoyed, without reading any code. One, Tree Appreciator, is a spot-the-difference game made in a single prompt. He thinks GPT-6 Astra is not quite as good at fun yet. His view: the hard part now is coming up with fresh game ideas.
