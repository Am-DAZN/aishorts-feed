BuggyMLE Plants Bugs in AI Code to Train and Test Coding Agents

Researchers built BuggyMLE, a way to test and train AI agents that do machine learning engineering, such as fixing broken training code across many files. Agents insert controlled bugs into working projects. The team made over 6,600 bug-filled versions from 222 source projects. They also made a difficulty score, the Code Complexity Index, which predicts how often models solve coding tasks. On the new benchmark, the best solve rate falls from 95% on the easiest tier to 9% on the hardest, across 14 models. Training a small Qwen3.5-9B model on this data helped it rival top models on the benchmark. It also improved on SWE-bench Lite, from 24% to 33%. This suggests harder, graded tests can make AI coding agents stronger.
