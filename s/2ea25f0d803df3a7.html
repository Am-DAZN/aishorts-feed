LoopVQ shrinks memory use of looped language models to under one bit per value

Looped transformers reuse the same layers several times, so a small model can match much larger ones. But each loop step still saves its own keys and values (the KV cache, a short-term memory the model uses while writing). That cache grows with every loop and becomes the main memory problem. Researchers noticed the cache is very repetitive across loop steps, and that some steps handle compression better than others. Their method, LoopVQ, compresses several loop steps together and tunes its codebooks to match the full-precision model's output. At 0.5 bits per value, it beat existing methods on reasoning and long-context tests with Ouro and Huginn models. Paired with TaSQ, it kept much of the accuracy at 0.25 bits. In SGLang, it nearly halved decode time at 32K tokens and raised peak throughput by up to 4.3 times and 6.1 times on two Ouro models.
