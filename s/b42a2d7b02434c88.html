New Method Predicts and Fixes Clashes When Merging Fine-Tuned AI Models

Model merging combines several AI models, each fine-tuned for a different task, into one by adding their changes to a shared base model. Tasks can interfere with each other, and people usually only find out after building and testing the merge. This paper shows that a simple measure of how one task's output shifts under another task's changes can predict this interference, but only when measured at the right point, the fine-tuned model itself rather than the original base. Using this, the authors build LR-Merge, which tunes merge settings using unlabeled data and no backpropagation through the merged network. It improved every base merging method they tested, with larger gains as more tasks were merged. It matches a costlier exact approach that took about three times longer to converge, and answers new queries in seconds.
