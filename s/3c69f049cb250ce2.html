ICARE helps text classifiers learn new tasks without forgetting old ones

AI language systems often forget earlier tasks when they are trained on new ones. Researchers call this catastrophic forgetting. Replaying old labeled examples can make it worse, because the system overfits and struggles with new categories. A new framework called ICARE aims to fix this. It has two parts. First, an instance selection step picks the best training examples to show the system. Second, knowledge distillation passes what the system already knows from one task to the next, covering both its internal features and its final decisions. The authors say tests on benchmark text classification datasets showed a significant gain in accuracy on target tasks and less forgetting. The source code is public.
