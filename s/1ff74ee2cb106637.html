Cogent and OpenAI team up to automate fixing security flaws

Cogent is working with OpenAI to help companies fix software security problems faster. The company combines OpenAI's AI models with details about each business's own systems. Using that context, AI agents, which are programs that can carry out tasks on their own, can automatically fix vulnerabilities. A vulnerability is a weak spot that attackers could use to break in. The source calls the setup a cyber defense factory for enterprises. It matters because security teams often face long lists of flaws to repair, and automation could help them keep up.
