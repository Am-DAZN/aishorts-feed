OpenAI explains how the Codex sandbox limits what it can do

OpenAI has published a blog post that looks inside the Codex sandbox. A sandbox is a walled-off space that keeps a program from touching things it should not. The post shows how Codex runs commands on your own machine while following limits you set. Those limits cover which files it can reach and what network access it has. The system works on macOS, Linux, and Windows. This matters because AI coding tools that run commands can do real harm if they are not kept in check. Clear controls help users decide how much freedom to give the tool.
