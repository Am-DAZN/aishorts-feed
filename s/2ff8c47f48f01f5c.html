datasette-leaflet 0.3 fixes map tile requests to OpenStreetMap

Simon Willison has released version 0.3 of datasette-leaflet, a plugin that bundles the Leaflet mapping library so other Datasette plugins can use it. OpenStreetMap asks that requests to its hosted map tile server include a referrer header, which tells the server which site the request came from. Datasette table pages sent a no-referrer header, so plugins loading OpenStreetMap tiles broke that policy. The update now sets the referrer policy on the tile requests themselves. It uses strict-origin-when-cross-origin, which passes the site's host but not the full page path. This keeps map plugins in line with OpenStreetMap's rules.
