DeepMind's AlphaProof Code writes 3 million lines of proofs for Signal encryption

Google DeepMind has introduced AlphaProof Code, a system of AI agents that checks software for mistakes. According to the company, the agents wrote three million lines of proofs in Lean to verify the core encryption used by Signal, the messaging app. Lean is a programming language used to write formal proofs, which are step-by-step arguments a computer can check for correctness. Verifying code this way can show that software does what it should, rather than just testing it. The source gives few other details, but the result points to AI helping with hard, large-scale security checks.
