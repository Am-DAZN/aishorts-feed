New 'external sandbox' keeps coding agents' code away from your machine

Simon Willison worked with Prime Radiant, an AI research lab, on a safer way to run code written by AI agents. In the external sandbox pattern, the agent stays outside, while the code it runs executes inside a sealed sandbox. This limits damage from mistakes or prompt injection attacks, where hidden instructions trick an AI into harmful actions. The team released three sandbox servers, built on v86 with WebAssembly, Apple Containers, and Microsoft's Quicksand. All offer the same local API, so tools like Pi, Claude Code, or Codex can use them. An optional proxy limits which websites the code can reach. It can also swap in credentials, so the agent never sees the secrets.
