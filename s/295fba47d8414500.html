RepoFactory Turns Real Code Repositories Into Training Grounds for Coding AI

Researchers built RepoFactory, a tool that turns real software repositories into practice environments for AI coding agents. In each one, the agent must build a whole project from scratch, starting from a written description. A feedback loop then improves the environments using quick, cheap checks instead of slow full training runs. It scores each environment on whether it works, how tightly its parts connect, and how much code it covers. The team made 10,159 environments across 17 software areas. They trained the Qwen3.5-35B-A3B model on them and got RepoHorizen-35B-A3B. It gained 22.6 points on NL2Repo-Bench, versus 17.5 without the feedback loop. Across five benchmarks, it gained 8.5 points on average, versus 6.4. This matters because long coding tasks need good, checkable training setups.
