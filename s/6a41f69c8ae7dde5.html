AI Coding Model Designs Robot Control Code, Boosting Success Without Retraining

Researchers built RoboArchitect, a system where a coding model watches a robot try tasks, finds why it fails, and rewrites the control code around it. This code, called a harness, decides when to ask the robot's AI policy for help, use vision tools, or move the arm directly. The policy itself is never changed. On unseen scenes, average success rose from 9.7% to 43.3%. On unseen tasks, it rose from 12.7% to 40.2%. The system found sensible tricks, like lifting a jammed arm or reaching in sideways around an obstacle. It also built its own memory, such as good grasp depths. This matters because harnesses are usually built by hand for each robot, and this suggests that work can be automated.
