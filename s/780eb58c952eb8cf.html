WorldFoundry: Open-Source Toolkit to Test and Compare AI World Models

Some AI video tools make realistic clips, but that does not mean they truly understand how a world works. A good world model should remember the state of a scene, react to actions, and show believable outcomes. Researchers define what a world model must do and build WorldFoundry, an open-source system for running and judging such models. It covers video, 3D, 4D, robot actions, and interactive worlds. It handles setup, running tests, storing results, and viewing them. Its scorecards keep a model's ability to run separate from claims about quality, so each claim can be traced to evidence. The catalog lists 270 models, 74 benchmarks, and 62 metrics. The goal is fair, repeatable comparison across very different systems.
