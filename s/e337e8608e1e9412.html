New Benchmark Tests How Well AI Agents Speed Up Whole Programs

Researchers released Accelerate Bench, a test of whether AI coding agents can make entire programs run faster without breaking them. It has 32 CPU tasks drawn from scientific software and supercomputing contests. Each task gives a working program and rules on correctness and timing, and the agent decides what to change. The team tested 16 agents, each a model paired with a harness (the tooling around it). Scores ranged from 25.5% to 67.4%. Most programs were correct, but speedups set agents apart. The top two were at least 2x faster on 22 or more tasks. The rest hit that mark on 8 to 17. Tests also showed that changes interact: the same code ran from 0.29x to 2.12x speed depending on build settings. This matters because real optimization needs coordinated changes across a whole program.
