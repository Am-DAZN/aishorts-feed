Not all data leaks inflate AI test scores equally, study finds

Data leakage happens when information from test data sneaks into model training, making results look better than they are. A new paper tests five common types of leakage on six public datasets and two synthetic tests, using three model families. That gave 600 paired comparisons of clean versus leaked setups. Leaks that use the answer labels or reuse data raised scores the most. Target encoding before splitting added 2.42 points of ROC-AUC, a common accuracy measure. Feature selection before splitting added 1.93 points, and duplicate rows added 1.52 points. Scaling or filling in missing values using all the data had almost no effect in the settings studied. Target encoding got much worse when categories were rare. The authors say teams should block all leakage, but check label-based steps and reused data most closely.
