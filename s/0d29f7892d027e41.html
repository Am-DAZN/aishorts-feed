FinEvo lets an AI model teach itself better financial modeling

Researchers have built FinEvo, a framework in which a single language model improves its own skill at financial modeling. The model sets up financial tasks, makes them harder through self-play, and learns from the results. It uses executable rewards, meaning code checks that show whether an answer works. Tested with the Qwen3.6-27B model, whole-task success rose from 22.73 to 29.09 on held-out tasks from the same sources. On SpreadsheetBench 2 Financial, it rose from 13.13 to 19.19. The model also improved on a task type it never saw in training. The authors say this suggests real, shared financial skills were strengthened. They see it as a step toward models that improve themselves in professional fields. The code is publicly available.
