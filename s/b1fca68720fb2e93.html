datasette-charts 0.2a1 brings small interface fixes for charting data

Simon Willison has released datasette-charts 0.2a1, an early test version of a plugin that draws charts for Datasette, a tool for exploring data. The update is mostly about small interface changes. Collapsing the suggested charts section now keeps the chart on screen. Opening a link to a chart shows it with suggestions folded away for that visit. On table pages, the panel now sits below the line that shows the row count. The data table under each chart is gone, replaced by buttons to copy the data as TSV or CSV. The "Chart this data" item was removed from the action menus. Chart tooltips also have more space between lines.
