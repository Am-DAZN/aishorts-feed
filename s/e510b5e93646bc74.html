Smaller looped image model matches Stable Diffusion 3 using far fewer parameters

Researchers present Distill to Loop, or Dooop, a way to shrink a large image-generating model. Looped models reuse one block of weights again and again instead of stacking many different blocks. Past looped models were trained from scratch, which is costly. Dooop instead teaches a looped student to copy a pretrained model, starting from the teacher's own blocks. The student can run any number of loops at test time without retraining. On SD3-medium, a student with about 37% of the teacher's parameters matched it on average across four quality tests using two to four loops. With two loops it used about 58% of the teacher's compute. A trick called loop guidance, which compares outputs from different loop counts, also improved images. On a four-step SD3-medium, it lifted the average score from 88.2 to 99.2.
