New Method Shrinks Image Datasets for Self-Supervised AI Training

Researchers have introduced MIPA, a way to squeeze a big image dataset into a small set of synthetic images. This is called dataset distillation. It has worked well for supervised learning, where data comes with labels, but little for self-supervised learning, where AI learns from unlabeled images. MIPA treats each synthetic image as a prototype, or reference point. A frozen encoder, which is a fixed model that turns images into numbers, matches real images to these prototypes. The method pushes the matches to stay the same across different edited versions of one image. It also stops all real images from collapsing onto just a few prototypes. In tests on image classification, MIPA's synthetic data produced better representations than existing methods. It also needed less time and storage to create.
