CurvDelta helps AI models learn or forget without losing other skills

When researchers adapt a large language model to a new task, it can lose some of its general abilities. A new method called CurvDelta aims to prevent that. It studies how sensitive the original model is to changes, then limits updates to directions that barely affect what the model already does well. It uses a math shortcut called K-FAC to make this work on big models. The team also built CurvLoRA, a lighter version that adapts the model more efficiently. In tests on math reasoning and code writing, the methods matched competing approaches on the new task while keeping more general skills. For unlearning, which means making a model forget specific knowledge, results on the TOFU and MUSE benchmarks showed a better balance between forgetting and keeping other knowledge. Retention came close to retraining a model from scratch.
