Datasette-llm 0.1a10 fixes bug in model restrictions

Simon Willison has released version 0.1a10 of datasette-llm, a plugin that connects the Datasette data tool to large language models (LLMs, the AI systems behind chatbots). This update fixes a bug found on his agent.datasette.io demo site. The site was supposed to offer only the AI models listed in its settings. Instead, the list of available models was not correctly limited to those. The fix makes the plugin respect the configuration. It matters for anyone who wants control over which AI models a Datasette site can use. The release is an early alpha version.
