Python 3.15 error? Simon Willison says delete your uv.lock file

Developer Simon Willison has hit confusing dependency errors since moving to Python 3.15. His fix is simple: if in doubt, delete the uv.lock file. A lock file records the exact version of each package a project uses. Most of his projects are libraries, so they do not commit this file. Running uv run pytest still creates one, though. Sometimes it pins a package version that has no ready-made build for Python 3.15. One example failed to build watchfiles 1.1.1, because the tool PyO3 only supports up to Python 3.14. Deleting the file and running the command again usually solves it.
