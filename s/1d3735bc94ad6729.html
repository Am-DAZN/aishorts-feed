Lab2Sim Turns Science Experiment Videos Into Interactive Virtual Labs

Science experiment videos show how a test is done, but students can't interact with them. Researchers built Lab2Sim, a test set of 218 science experiment videos with detailed specifications and 11,881 checklist items for grading results. They also created EduVideo2Code, a method that turns a video into a working interactive web page. It first pulls out the experiment steps in layers. It then writes them as a state machine, a set of rules for what can happen next. These rules help the AI write code and respect conditions, such as what must be done before a step. Finally, it runs the code and checks it to fix problems. Tests showed that current AI models that handle images and text can easily make pages that run, but they often get the lab equipment wrong. EduVideo2Code improved all four measures across two base models, and equipment accuracy rose by 24.15 points.
