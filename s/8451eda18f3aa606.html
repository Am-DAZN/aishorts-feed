TokenEconomizer plugin cuts AI coding agent costs by up to 31%

Coding agents often start every session from scratch, even in the same codebase. They relearn basic facts, load tools they never use, and repeat failed fixes. Each of these steps uses tokens, the units AI models charge for. TokenEconomizer is an open-source plugin from UC Berkeley, Microsoft Research, and Microsoft Security. It reads logs of past sessions and gives future sessions short guidance, without changing the agent or its model. It adds repository notes, removes unused tools, and nudges a stuck agent to try something else. On 277 real bug-fixing tasks, costs fell 18.4 to 30.9% across several agents. Costs dropped in every repository tested, and success rates stayed broadly stable.
