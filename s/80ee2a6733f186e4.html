Datasette Agent 0.7a1 improves side panel navigation

Simon Willison has released datasette-agent 0.7a1, a small update to Datasette Agent. In this tool, chat sessions can open a side panel that shows a web page, and that panel can move to other pages. The new version handles fragment hashes better. A fragment hash is the part of a web address after the # sign, which some plugins change when a user does something. Better handling means the agent works more closely with those plugins. Willison says he built the update to fix bugs in the datasette-charts 0.2a0 release, which he calls much more exciting.
