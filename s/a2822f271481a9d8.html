New AI layer design makes language model features easier to read

Language models often spread one idea across many internal dimensions, which makes them hard to interpret. Researchers propose Mixture of Wide Experts, or MoWE. In this design, each selected expert reads the full input but writes to its own fixed set of output coordinates. In tests, MoWE scored 2.417 on evaluation loss versus 2.452 for a dense model, while a standard mixture-of-experts model reached 2.22. Lower is better. A language-model judge rated how clearly each coordinate could be described. MoWE scored 0.523, against 0.375 for dense and 0.268 for standard MoE. The authors also traced a path behind a model's answer about angles and steered another to refuse hazardous requests. This suggests models can be built with readable parts from the start.
