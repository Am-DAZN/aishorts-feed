Researchers chain several flaws to hijack ChatGPT accounts through shared links

Parameter Labs found a way to take over ChatGPT accounts using the tool that shows custom HTML apps, called HTML previews. These apps run in a sandbox, a locked box meant to keep untrusted code away from private data. The attack chained several weak spots. A math library's keyboard feature let sandboxed code inject HTML into the main page. That let the attacker add a frame with no sandbox. OpenAI's security rules allowed scripts from YouTube, and a YouTube endpoint could be tricked into running attacker code. With that, private data could be stolen. A shared ChatGPT link could hit any signed-in user who opened it. OpenAI fixed the hole and paid a $5,000 bug bounty. Writer Simon Willison thinks that was low for such a serious flaw.
