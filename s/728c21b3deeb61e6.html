Count shipped code, not tokens, to judge AI coding costs

AI coding agents plan, write, test and retry code, so one task can use 10 to 50 times more tokens than a normal chat prompt. With per-token pricing, the most useful work gets the most expensive. Uber reportedly used up its 2026 AI budget by April, and Gartner expects AI coding token costs to pass developer salaries by 2028. This MIT Technology Review piece says usage caps miss the point. It suggests tracking cost per merged pull request, meaning a code change that passes review, alongside rework and defects. It also urges using costly frontier models only for hard planning, and sending routine work to open-weight models a company runs itself. At HPE, this approach cut token costs by 30 to 50%.
