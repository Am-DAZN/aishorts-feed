OpenAI builds system that finds and patches 948 Linux kernel flaws

OpenAI says it built an automated pipeline that hunts for security bugs in the Linux kernel, the core software behind many servers and devices. The system found 948 local privilege-escalation vulnerabilities. These are flaws that let someone who already has limited access to a computer gain full control, often called root access. The pipeline did more than spot the problems. It also checked that they were real and generated patches, which are code fixes. The source gives no further detail on how it works or how many fixes have been adopted. The work points to AI tools doing more of the slow, repetitive security work that people usually handle.
