EDGAR Uses Diffusion to Clean Up Flawed 3D Head Avatars

3D head avatars built from a single video or image often look flawed. They can appear blurry, stretched or flickery over time. EDGAR is a new tool that fixes these problems while keeping the person's face recognizable. It is a diffusion model, a type of AI that cleans up images step by step. To train it, the team built a dataset that pairs damaged avatar renderings with true photos and reference images. EDGAR then uses the cleaned views as targets to improve one underlying avatar. This means the final avatar can be shown without running EDGAR on every frame. Tests on three avatar methods showed better results than the raw outputs and a similar baseline. It also held up with large head turns and open mouths. The code is public.
