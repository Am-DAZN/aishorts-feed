G-CAST Lets Shopping AI Agents Keep Learning as Demand Shifts

Shopping agents powered by large language models face a moving target. Customers ask for new product types and features, and the agent's tools and procedures keep changing. A model trained once soon falls behind, and manual retraining is slow and costly. The paper presents G-CAST, a system that learns from daily production data. It sorts that data using rewards and picks the most uncertain examples first. Each model update is checked against past tests, so the agent picks up new skills without losing behavior users already rely on. On a real production agent, G-CAST adapted better to new demand and kept old behavior better than a strong baseline. It is now deployed in Yuancai, a B2B procurement agent on Alibaba's 1688 platform.
