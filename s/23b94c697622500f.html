CodeRabbit uses OpenAI models to ship 20x more software

CodeRabbit, a company that builds tools to review code, says it uses OpenAI models to check and trust code written by AI. It also uses Codex, OpenAI's coding tool, to build its own software faster. According to OpenAI's blog, the company now ships 20 times more software with the same engineering team. The post points to a wider shift, where AI helps write code and other AI helps check it. The source gives few other details on how the results were measured.
