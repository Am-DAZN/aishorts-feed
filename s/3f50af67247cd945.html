Datasette 0.65.6 patches a database download access flaw

Simon Willison has released datasette 0.65.6, a small update to his open-source tool for publishing and exploring data. It backports a minor security fix from version 1.0a43. The bug affected databases added with add_database using a route that differs from the database's name. In that case, people who had been denied access could still download the database as a .db file from its route address. The fix closes that gap. Anyone running the 0.65 line of Datasette with custom database routes should consider updating.
