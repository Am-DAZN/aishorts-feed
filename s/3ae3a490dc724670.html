LLM 0.37.3 fixes logging bug caused by SQLite update

Simon Willison released LLM 0.37.3, a bug fix for his LLM tool. The problem showed up in the newest Homebrew package, which now ships SQLite 3.54.1. SQLite is a small database that LLM uses to log its activity. A fix in that version changed how a nested query returns data. Before, it gave a real JSON list, like {"a":[1]}. Now it gives plain text, like {"a":"[1]"}. That change broke LLM's logging code. SQLite's creator, D. Richard Hipp, said the new behavior is correct and the old one was a bug. The workaround is to wrap the inner query in the json() function, which turns the text back into JSON.
