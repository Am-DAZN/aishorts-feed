WorldRuler Lets AI-Generated Game Worlds Follow Rules Set by Users

Researchers have built WorldRuler, a system that makes AI-generated interactive worlds obey custom rules, not just real-world physics. It stores rules, their links, and the state of each object in a 3D rule graph. That lets a saved world be reloaded with the same rules still in force. The system also ties rules to specific objects in the video, even ones not yet on screen, so changes appear on the right items. The team also built RuleVerse, a dataset made from GTA-V and Habitat with detailed notes on states and events. Tests show it keeps rules consistent across saving and loading and applies rule effects to the intended objects. This matters for games where players want to design their own rules.
