Ladybird, a from-scratch web browser, ships its first alpha release

Ladybird, a new browser built mostly from scratch, has released its first alpha version. You can now install it on macOS or Linux without compiling it yourself. It has its own HTML, CSS, JavaScript and WebAssembly engines, though it still uses a few outside tools like ffmpeg and SQLite. Simon Willison tried it and found it fast, light and mostly working well on the sites he tested. One tool, Datasette Lite, failed because of a missing service worker feature. The team also leaned on AI coding agents this year, which helped add tens of thousands of passing web-standards tests in one month.
