Telling Claude Fable 5.2 the Code Is 'Yours' Changes How It Edits

Anthropic's guide for prompting Claude Fable 5.2 says the model pays close attention to who owns the code it works on. If a prompt says nothing about ownership, or calls the code someone else's, the model tends to add to what is already there, even when that repeats existing code. Anthropic suggests a fix: tell the model the codebase is its own, and that what it's for and how it's built are its call. In Anthropic's tests on small coding tasks, the model merged repeated code in about half of tries with that sentence. Without it, this happened in under a tenth of tries. A single line in a prompt can shift how tidy the result is.
