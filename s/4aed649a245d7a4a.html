Giving AI Agents Live Tool Health Data Cuts Costly Mistakes

AI agents that use tools often pick actions blindly. They know what a tool does, but not whether it is working well right now. The host system usually has that information, but the model does not. The authors call this gap operational blindness. They propose Agent Harness Awareness, where the host gives the model a small, fresh, verified status snapshot before a key action. The host still controls measurement, enforcement and the final decision to run the action. In a test of 216 decisions across three models, this status data cut observable regret, a measure of wasted time, by 96.9%. Tasks finished on the first try 95.8% of the time, up from 69.4%. A smaller live test with injected network faults showed similar gains: the action completed in 9 of 9 cases versus 5 of 9 without the data. Other uses, such as hardware pressure and retries, remain untested.
