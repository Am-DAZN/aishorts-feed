New Method Fixes Missing Sensor Data Without Hiding Real Faults

Factory sensors often lose chunks of data to network drops or hardware faults. The usual fix fills the gaps first, then looks for anomalies. But the filler tends to guess normal values, so it can smooth over a real problem and also cause false alarms. Researchers call this imputation bias. They propose TADR, a diffusion model (an AI that refines data step by step) trained with a fixed anomaly detector in mind. On the SMD dataset, it raised F1 score, a measure of detection accuracy, by 0.338. It does not help on some datasets, such as ones dominated by on/off command channels. On one CPU core it takes 41.4 ms per window and can handle about 24 sensor streams at once. Code is public.
