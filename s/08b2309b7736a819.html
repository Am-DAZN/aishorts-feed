New AI Network Speeds Up Uncertainty-Aware Earth Imaging From Sparse Data

Geophysicists try to picture what lies underground using limited, noisy measurements. This is hard because many different answers can fit the same data. A common statistical method, MCMC, tests many possible answers but needs huge amounts of computing. Standard machine learning can be faster, but it may give physically unrealistic results when training data is scarce. Researchers propose a model called GI-ION to fix this. It uses an invertible neural network, a type of network that can run both forwards and backwards, inside a framework that learns the physics of the forward problem. It also tracks uncertainty, so it can quickly draw many likely answers. The team tested it on surface-wave dispersion in 1D and on travel-time tomography in two 2D models, including a seismic slice. They report robust results and efficient sampling, even with sparse observations.
