New benchmark tests AI agents that make videos by writing code

Researchers released VibeVideoBench, a test for AI agents that build videos by writing code instead of using video-generating models. Regular video models struggle with exact formulas, correct charts and narration that matches the screen. The benchmark has 239 tasks in English and Chinese, such as data stories, classroom lessons and paper explainers. Each agent has one hour to deliver a finished MP4 with sound. Nine top agent systems were tested. GPT-6 Astra and Claude Opus 5.5 ranked first and second, agreeing with human reviewers. The best system met every core requirement on 76.3% of tasks. Many failures were not about quality. About three quarters of lost videos came from final renders that started too late, ran too slowly or never began. This shows agents still plan their time poorly.
