TPHC Tweaks Transformer Residual Streams for Better Results at Little Extra Cost

Researchers propose TPHC, a way to improve a Transformer design called Hyper-Connections. These split the model's main information path into several parallel streams. A newer version, mHC, keeps them stable but gains little beyond four streams. One reason is that every layer writes the same output to all streams. TPHC uses tensor parallelism, a method that splits work across several chips. Each chip gets a different mix of streams, and its output stays separate when written back. So each stream can be updated differently, without adding parameters or compute to the attention or feed-forward layers. On an 8B model, TPHC needs 9% more training time than mHC with four streams. On a 1.1B model, it cut validation loss by 0.7-1.0% and raised average accuracy on six reasoning tests by 0.3-0.7 points. Code is public.
