PAD Scores Driving Data by How Much It Helps Each Self-Driving Model

Self-driving systems learn from recorded human driving demonstrations. But more data does not always mean better driving. A clip that helps one model can be useless or even harmful to another. This paper introduces PAD, a method that gives each demonstration a value tied to the specific driving model being trained. It uses feedback on how the model handles scenes, plus gradients, which show how training would shift the model. Tests showed different models rank the same data very differently. On DiffusionDrive, PAD improved the EPDMS driving score by 3.5 points on NavTest and 5.0 on NavHard, compared with real data alone. It also beat training on the full data pool across several model types and cut scene-level regressions, where the model gets worse on scenes it handled before. The authors say this could replace piling up data with picking the data each model needs.
