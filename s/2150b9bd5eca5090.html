Click3R lets users fix 3D reconstruction errors with a few clicks

Some AI models can build a 3D scene from two photos in one quick pass. But they give a single answer, and if it is wrong, there is no way to fix it. Click3R adds that missing step. A user clicks on matching points in the two images, and a small add-on module feeds those clicks into the model as hints about the scene's shape. This helps in hard cases like repeating patterns, symmetric objects, big changes in viewpoint, or blank surfaces. The researchers also built a new test set designed to expose where current models fail. They report that even one click lowers the reconstruction error, on both standard tests and their new one. The work suggests that a little human input can be a practical way to correct 3D mistakes.
