MEM-SQL Lets Database AI Reuse Past Queries to Answer New Ones

Text-to-SQL tools turn plain questions into database queries. Most tests treat each question alone, ignoring earlier queries on the same database that could help. Researchers built HARE, a benchmark of 1,600 requests based on 823 verified queries across four datasets. They also built MEM-SQL, which stores whole query templates, reusable pieces of SQL, and links between everyday concepts and database fields. It checks the database layout only when its memory falls short. Across six language models, average accuracy rose from 37.1% to 50.0%, while using 76.6% fewer input tokens and 68.8% less time. Requests that need several past queries remain hard, with accuracy dropping from 56.7% to 29.7%. The work suggests verified history can make these systems both better and cheaper.
