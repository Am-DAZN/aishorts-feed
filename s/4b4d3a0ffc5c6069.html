MillBill Agent Lets AI Plan Machining While Software Checks the Geometry

Turning a 3D design into a machining program takes both craft knowledge and exact geometry. Many AI approaches ask a language model to write all the code for shapes and cutter paths, which makes it do precise math too. MillBill splits the work. A mid-sized open model, run locally, picks the machining steps and cutting settings. A separate software tool then builds the cutter paths, simulates the material being removed, and sends feedback so the plan can be improved. Setup planning also considers what the cutters can physically reach, not just what they can see. Scored by how much of the target surface ends up within tolerance, MillBill with Qwen3.8-27B beat approaches using frontier models that build their own geometry and toolpath workflows. The code is public.
