Video AI Models Repurposed to Teach Robots How to Move

Researchers found a way to pull out the "actions" hidden inside videos, such as human hands or robot recordings, which usually have no action labels. They reuse a pretrained video-generating model and add a few small learnable parts that squeeze each video's motion into a compact code. This code is called a native latent action. It beat earlier methods on the LARY benchmark and could replay the same motion on new robots, in new scenes, and from human hands to robots. The team then used it to pretrain robot control models, called PAWlicy. A 3.8B-parameter version reached a 93.6% average success rate on RoboTwin 2.0, the highest among similar models. It also beat the pi_0.5 baseline on two real robot tasks. Everything uses only public data and a public world model.
