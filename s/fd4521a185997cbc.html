Microsoft builds fake company data to test Copilot without touching customer info

Microsoft Research has built a system called the Industry Evaluation Data Generation Platform to test Copilot, its AI assistant. Real company data is too sensitive to use for testing. So the team creates fully synthetic, or made-up, workplaces with users, meetings, emails, documents and org charts. These are based on public sources such as O*NET job data, online job postings and SEC filings. The system also generates test questions automatically and checks data quality. Automated safety checks keep out harmful or personal information. Microsoft says these realistic setups help it find problems that generic tests would miss, and set a first standard baseline for Copilot.
