Team builds AI pipeline that writes fact-checking articles, ranks 3rd of 9

False claims spread faster than human fact-checkers can check them and write up their findings. A team called DS@GT ARC tried to automate that writing for a shared contest, CLEF 2026 CheckThat! Lab Task 3. Given a claim, the original verdict and a set of scraped web documents, their system produces a full fact-checking article. It works in four stages. It cleans messy evidence, finds and groups relevant sources, writes the article with the Llama-3.1-8B-Instruct language model guided by the original verdict, and then adds source citations using fixed rules. The team scored 0.428 on average and placed third out of nine teams. The baseline scored 0.272. The code is public on GitHub, so others can reuse it.
