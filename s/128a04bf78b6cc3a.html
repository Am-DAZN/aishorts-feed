Simon Willison releases datasette-maplibre, a new map plugin built mostly by AI

Simon Willison has released an early version (0.1a0) of datasette-maplibre, a new mapping plugin for Datasette, his tool for exploring data. It pairs the MapLibre GL map library with OpenFreeMap, a free map server run by Zsolt Ero. Willison built most of it with a single prompt to Claude, asking it to combine the features of two older map plugins and add creative ideas. One result: shapes first show as light SVG previews, and a full WebGL map loads only when they scroll into view. A demo runs in Datasette Lite, right in the browser, and shows shapes and points on one map.
