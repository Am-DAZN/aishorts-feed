Reinforcement Learning Agent Searches for New Physics Theories in Particle Data

Physicists often see measurements that differ from the Standard Model, the main theory of particle physics. One broad framework for explaining these gaps is called SMEFT. The trouble is that it has a huge number of possible building blocks, called operators. They affect many measurements at once, and different mixes can fit the data about equally well. This paper treats the search as a step-by-step decision problem and uses reinforcement learning, where an AI agent learns by trial and reward. The agent is small, with about 40,000 trainable parameters. It aims to find many good theory candidates, not just one best fit. The team tested it on 132 measurements, including 24 that differ from Standard Model predictions by more than 1.5σ. The agent built multi-operator theories that clearly improved the overall fit, and it did better than random searches.
