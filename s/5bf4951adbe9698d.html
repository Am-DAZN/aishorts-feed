OpenAI launches ChatGPT Wallet for AI agent purchases

OpenAI has introduced ChatGPT Wallet. It is a way for AI agents to buy things on a person's behalf. The agents work inside ChatGPT Work, Codex, and dots. Each purchase needs the user's approval first, so the agent cannot spend money on its own. The wallet also keeps the protections that a user's existing card already offers. This matters because AI agents are being asked to do more tasks for people, and paying for things is a sensitive step. OpenAI's short announcement gives no further details on how it works.
