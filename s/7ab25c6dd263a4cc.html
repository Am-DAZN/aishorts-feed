Microsoft's PDD Kit proves AI-written web app code matches the plan

Microsoft Research released PDD Kit, a toolkit that turns a developer's intent into a formal spec, a precise math-style description of what code must do. It then uses a tool called Verus to prove the code an AI agent writes meets that spec for every possible input. Where a proof can't reach, it falls back to tests. The team tried it on the login logic of Pet Store, a Rust web app, inside GitHub Next's Chopin. Verus found existing bugs and proved the login code free of bugs against the spec. The developer reviewed the intent, not the generated code line by line. It matters because AI agents now write huge amounts of code that humans cannot review in full.
