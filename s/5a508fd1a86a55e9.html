Robot coding agents learn from real-world tries and reuse skills

Researchers built PyRUA-REAL, a framework where AI coding agents improve robots by trying tasks in the real world. The agents write robot code, test it on physical objects, and fix it based on what happens. They keep their experience as memory and save working code as reusable skills for later tasks. The team studied how agents work together, what feedback helps most, and how earlier skills help new tasks. The final programs can also run without an AI agent making decisions live. Across eight real-world tasks, the system succeeded 91.1% of the time on average. On 42 tasks from the RoboDojo benchmark, it reached 84.4%. The study offers guidance on turning physical practice into lasting robot skills.
