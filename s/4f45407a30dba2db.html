New Trick Speeds Up Feedback Transformers by Up to 2.8x

Some Transformers, the models behind modern chatbots, get better by feeding each step's internal state back into the next step. But this breaks speculative decoding, a speed-up method where a model drafts several words ahead and then checks them. The check needs a state that isn't ready yet, so the draft uses a rough stand-in. Researchers propose Feedback Shortcut to fix this. It trains a small add-on to make better stand-ins, without changing the main model. It also re-checks each draft using the real state once it is computed, with no extra calls. On models of 135M and 780M parameters, quality stayed very close to the exact-decoding ceiling. Decoding ran 2.4 to 2.8 times faster, with about 2% more training compute.
