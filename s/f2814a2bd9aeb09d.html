FlowTranslator Translates Text Inside Images Without Any Extra Training

Researchers have built FlowTranslator, a tool that swaps the text in a picture for its translation while keeping the rest of the image intact. Earlier tools needed huge sets of paired images, one before translation and one after. This one needs no training. It uses an OCR model to read the text and a language model to write the translation. That prompt then goes into an existing text-to-image model that can already write in many languages. Two added controls help the new text look accurate and natural. In tests, it scored 20.6 on BLEU and 57.2 on COMET, two translation quality measures, beating a trained baseline called UniTranslator. On real photos translated into Chinese, it got 40.1% of the text exactly right. The authors say this makes a strong, training-free starting point for the task.
