OpenAI and Cisco release Shirudo, an open-source Linux runtime

OpenAI and Cisco have introduced Shirudo, a new open-source runtime for Linux. A runtime is software that runs and manages programs on a computer. According to the announcement, Shirudo helps teams protect systems that are already running while they roll out patches, which are software fixes for security problems. Open-source means anyone can view and use the code. The source gives no further details about how it works or when it will be available.
