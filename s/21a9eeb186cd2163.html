WeLM-Image: One Model for Making and Editing Pictures in WeChat

WeLM-Image is a new image model built for WeChat's large consumer apps. One model handles three jobs: creating images from text, editing images from instructions, and combining several reference images. It reads text, reference images and the image being made as one sequence. The model stores 31.7 billion parameters (its learned settings), but only about 5.4 billion are used for each piece of the image, which keeps it light enough to run on a single GPU. The team trained it with bilingual labels and checked editing data, up to 1.5K resolution. On three tests, PRISM-Bench, Qwen-Image-Bench and UnicBench, the 1536-resolution version ranks first among the open-source models compared. A faster version, WeLM-Image-Turbo, makes a 1024 by 1024 image in 4.98 seconds on one NVIDIA H20 GPU. This shows strong image tools can run on modest hardware.
