Microsoft Research unveils Flint-interactive for building interactive AI-made charts

Microsoft Research has released Flint-interactive, a language for making interactive data charts. It is built on top of Flint, an existing tool. AI agents can already make charts, but static ones limit exploring. Users want to click, filter, zoom and highlight across charts and text. Doing this with AI is costly and often breaks, since agents need many rounds of coding and debugging. Flint-interactive lets users or agents describe interactions in simple, high-level terms. Flint's compiler, the program that translates instructions, turns clicks and selections into events that carry meaning, then updates the visuals. This handles tricky layout and dependency problems. It could make dashboards and data stories easier and more reliable to build.
