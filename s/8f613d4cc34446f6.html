MMMem Helps AI Agents Learn From Past Tasks Using Multimodal Memory

AI agents often build up chats, images, and documents over time. But they rarely keep what they learned from answering questions, so the same mistakes can come back. Researchers propose MMMem, a memory system that learns from finished tasks instead of only storing and looking up records. It links text, images, and page views to their sources, and makes new scene images that join clues across records. It also trains the model on tasks made from the source material. A vision-language model then turns each finished task into a short experience note with the context, the conclusion, and links to support. Tested on three memory benchmarks with two models, MMMem beat eight baselines. With Qwen3.5-9B, it gained 36.9%, 17.6%, and 15.2% over the best baseline on LoCoMo, Mem-Gallery, and LooGLE v2.
