Datasette-llm 0.1a9 sets a default model automatically

Simon Willison released version 0.1a9 of datasette-llm, a plugin that sits underneath Datasette Agent. The update is small but makes setup easier. The plugin now uses the default model already chosen in LLM, his tool for working with AI models. Before, users had to name a model by hand with an extra setting to start Datasette Agent. Now they can run the basic command with a database file and get going. Willison says bigger upgrades to Datasette Agent are still in the pipeline.
