Training AI Agents With Code-Managed Context Helps Them Handle Longer, New Tasks

Today's language models often work as agents inside a "harness," a wrapper that feeds them information. Usually that wrapper piles up context, which makes training on long tasks slow and costly. This paper tests a different design. The harness manages context with code and breaks big problems into small pieces, so the model only sees familiar-looking inputs. Using reinforcement learning, a harness called the Recursive Language Model learned this. Training on short tasks carried over to tasks 2 to 64 times longer, and skills moved to new domains with similar structure. The authors also trained on synthetic practice environments with fake tool calls. Their RLM-27B model beat Qwen3.8-27B in the same harness by 26.9% on average on hard long-context tests, using about half the tokens.
