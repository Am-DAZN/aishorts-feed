AI Coding Agent Replaces Human Robot Teleoperators to Generate Training Data

Teaching robots usually means a person remotely controlling them to record demonstrations. That takes robot and operator time, and each new task starts over. Researchers built PyRUA-DataFarm, where a coding agent does this job. It gets a request and one example episode of the real scene. It then builds the task in simulation, including the scene, an expert controller and a success checker. A video model turns each simulated run into realistic camera video. Policies trained only on this data matched teleoperation-trained ones on five real-robot tasks: 93 successes in 100 trials versus 84. With an unseen tablecloth and coloured light, they kept 87 successes while the others fell to 46. Setup costs about $21 in API use per task, plus $5 for rendering. Each extra episode costs about $0.80. One hour of three-view data costs about $107, slightly below a $117 teleoperation quote in China.
