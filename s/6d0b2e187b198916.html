New Benchmark Tests AI on Full Contest-Style Math Modeling Problems

Researchers released TB-MathModel, a test for AI agents on real-world math modeling. It uses 18 problems from two math modeling contests, CUMCM and MCM, from 2023 to 2025. Each agent works in a terminal inside a container, with the original problem text, files and figures. It returns one JSON file with its answer. The answer is scored against prize-winning human papers, and it only counts if it is physically feasible. Feasibility is checked by code and by 624 Lean 4 proofs, a tool for machine-checked logic. Beating the human reference is never penalised. Across seven multimodal models, the best scored 64.58%. An open model scored 59.81% at about 1/100 of the cost. The team says the benchmark gives a repeatable, checkable way to measure long-horizon modeling skill. The code is public.
