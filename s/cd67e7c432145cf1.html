Datasette's oldest untouched chart plugin gets first update since 2018

Simon Willison has released datasette-vega 0.7, a plugin for Datasette that draws charts from data in a table or from a custom query. It uses a tool called Vega-Lite to make the charts. The last release came in July 2018. This update makes it work with the latest Datasette alpha versions. It also adds small visual tweaks so it runs better in Datasette Lite. Datasette Lite has just gained the ability to run JavaScript plugins like this one. Willison says he will write more about that soon. Because the plugin now works there, the live demo in its README links to a demo on Datasette Lite.
