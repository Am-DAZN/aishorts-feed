Claude Rebuilds a 3D Egg in Plain JavaScript, No Library Needed

Developer Simon Willison tested whether an AI could make 3D graphics without a popular helper library. He first had Claude build a nudibranch-themed Faberge egg using Three.js, a common 3D tool for the web. The file was 77KB. He then asked Claude to port it to Vanilla JS, which means plain JavaScript with WebGL and no extra library. The result was 98KB. The two versions are not identical, and Willison says he does not fully understand why. He concludes Claude can do 3D modeling without Three.js. He finds the Three.js code a bit easier to read, but he rarely checks the code in these projects, so it matters little to him.
