Letting AI Models Decide When to Trim Their Own Memory

AI agents have a limited working memory, called a context window. Today, the software around the model usually steps in when it fills up and summarizes the history. This paper tests another way: the model itself decides when and what to shrink, using a context tool. Researchers built it into NVIDIA's open source agent software and tested it on document research and machine learning engineering tasks. Models that used the tool well scored higher, often with fewer input tokens, especially when memory was tight. GPT 6.1 went from 21% to 56% on one test at a 32K budget. Models differed a lot in how often and how early they trimmed. The team also cut some computing work by up to 15% by reusing saved data after an edit, with no loss in accuracy. They suggest training models to manage their own context.
