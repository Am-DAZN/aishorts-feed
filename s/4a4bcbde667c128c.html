AI Agents Now Help Run the Search for Alien Signals

Breakthrough Listen and the SETI Institute are using AI agents at the Allen Telescope Array in Northern California. A researcher can type one plain-language request, and the agents steer the telescope, fix data errors and run AI models on the incoming data. NVIDIA's Holoscan platform feeds the live data, which reaches terabits per second. The system handles 2.4 terabits per second on NVIDIA GPUs placed next to the telescope, so data is processed as it arrives instead of filling hard drives. The team says agents cut work that took humans weeks or years down to hours. The setup has already made the first real-time AI detection of a pulsar, a fast-spinning star remnant, in the Crab Nebula. Next, the team is testing open models such as NVIDIA Nemotron.
