Withholding Training Data Only Delays AI Skills, Study Finds

Developers often leave certain data out of training so models don't learn risky skills. This paper tests how well that works. The researchers withheld single skills from models trained on chess, Othello, molecular strings, bracket languages and web text. They found that a model's general progress on the rest of its data makes up for the missing data. A chess model never trained to respond to check still ranked legal moves almost as well as one that was. Later, when trained on the withheld data, models learned the skill using only a small fraction of the data needed from scratch. That fraction shrank as models improved. A similar effect showed up when a programming language was held out from a 7-billion-parameter model. The authors conclude that filtering data delays a capability, but does not block it, and regaining it gets easier as models get better.
