When AI Writes Model Weights by Hand, a Simple Table Beats the Transformer

Transformers became standard because they train well with gradient descent, a step-by-step tuning method, and run fast on GPUs. This paper looks at "weight-space programming," where a large language model writes a model's weights directly, with no training. Then those reasons may not apply. Researchers gave three leading LLMs ten labeled examples and a sandbox, mostly on multiple-choice questions. When free to design, all three turned text facts into a sparse table checked by a fixed procedure, reaching up to 54.4% test accuracy. One such model beat the best Transformer the same LLM wrote, with about 1,800 times fewer parameters. A table is easy to read, so the LLM can explain each weight and fix wrong ones. The authors propose a memory-based model up to 17 times faster on GPUs than a same-sized Transformer. Pretrained LLMs are still more accurate.
