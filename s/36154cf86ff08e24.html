SilentGuard Stops AI Agents From Trusting Quietly Broken APIs

AI agents often get answers by calling APIs, which are online services. Sometimes an API fails silently. It ignores part of a request, like a misnamed filter, but still says everything is fine and returns a wrong result. Researchers built SilentGuard, which checks each result against rules any correct API must follow. If a result breaks a rule, the system withholds it instead of asking the model to judge. The team found silent failures in 11 of 15 public research APIs. Across 7 open models, wrong answers on targeted faults fell from 74.0% to 1.7%. On three frontier models, they fell from 70.2% to 0.5%. Just warning the model left 70.1% wrong, so enforcement matters. The system avoids errors by holding back answers, not by fixing them.
