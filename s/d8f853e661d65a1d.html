GitHub's 2026 Octoverse report shows activity tripling as AI coding agents spread

GitHub released its yearly Octoverse report at its Universe event. Executive Jay Parikh shared the main numbers. Merged pull requests, which are code changes accepted into a project, tripled in under a year to 220 million per month. Commits, or saved code updates, more than tripled to 7.38 billion per month, mostly in the second half of the year. New repositories, the folders that hold projects, doubled to 30.3 million per month. Blogger Simon Willison calls this a stark sign of how agentic engineering, where AI agents write code, is affecting GitHub. The report also adds figures by industry and for projects tied to interoperability or reverse engineering.
