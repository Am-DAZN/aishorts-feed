Datasette plugin now works with locally hosted AI models

Simon Willison has released datasette-llm 0.1a11, a plugin for Datasette. Datasette is a tool for exploring data. The plugin lets you set up large language models (LLMs, the AI behind chatbots) for use with other Datasette plugins. This version adds support for OpenAI-compatible endpoints. These are servers that use the same web protocol as OpenAI, so the model can be hosted anywhere. That means people running local models with LM Studio, Ollama or llama.cpp can connect them to Datasette. The release notes say llama.cpp just reached version 1.0.0. A short command using uvx starts a local Datasette Agent powered by your own model. This matters because it lets people try AI features on their data without relying on a cloud service.
