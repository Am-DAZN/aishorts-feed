ToolSmith Lets AI Search Agents Build Their Own Tools

Some AI agents answer questions by searching the web and looking at images over many steps. Today they rely on a small set of tools that people write by hand. Those tools take effort to build and keep up, and they stay fixed even when new kinds of questions come up. ToolSmith is a new framework that lets the agent make new tools from simple parts it already has, then reuse them on later tasks, much as people do. It was tested on three in-domain benchmarks and ten out-of-domain ones, with another AI model acting as judge. It beat the basic tool set across agents of different sizes, and larger agents gained more. The code and data are public.
